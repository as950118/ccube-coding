# 수업 운영 원칙 — 차별화·템플릿·과제

## 1. 핵심 원칙

### 「같은 목표, 다른 길」
매주 **하나의 공통 🟢 목표**만 정합니다. 도달 방식은 학생 수준에 따라 다릅니다.

| 레벨 | 대상 | 하는 일 |
|------|------|---------|
| **🟢 Level 1 (기본)** | 처음·어려워하는 학생 | 템플릿 복사 → **2~3곳만 수정** |
| **🟡 Level 2 (표준)** | 대부분 | 함수·변수 이해하고 직접 조금 수정 |
| **🔴 Level 3 (도전)** | 빨리 끝나는 학생 | UI 개선, 기능 추가, 이전 주 기능 통합 |

> 🔴은 「더 어려운 다른 숙제」가 아니라 **같은 기능의 plus 버전**입니다.

### 「과제 ≠ 다음 수업의 입장권」
- 과제 안 해도 다음 수업 **100% 참여 가능**
- 매주 **새 starter** 제공 (지난 주 기능 포함)
- 수업 첫 15분 안에 전원 🟢까지 같이 도달

## 2. starter 템플릿 설계

### 매주 배포하는 zip 구조 (예시)

```
week05-starter/
├── index.html      ← 거의 건드리지 않음
├── style.css       ← 🟢: 색·글자만
└── script.js       ← 🟢🟡🔴: 주석으로 구역 표시
```

### script.js 주석 패턴

```javascript
// ===== [🟢] 여기만 바꾸세요 =====
const DEFAULT_QUESTION = "오늘 날씨 어때?";

// ===== [🟡] 아래 함수 이해하고 수정 =====
function sendQuestion() { ... }

// ===== [🔴] 도전: 아래 추가 기능 =====
// - Enter 키로 전송
// - 대화 기록 배열에 저장
```

### starter 2종 (선택)

| 파일 | 용도 |
|------|------|
| `week05-starter.zip` | 전원 — 🟢까지 거의 완성 |
| `week05-blank.js` | 🟡🔴 — 비어 있는 함수만 (직접 작성) |

## 3. 매주 과제 카드 형식

```markdown
## N주차 과제 (선택) ⏱ 약 10분

다음 수업 전까지 🟢만 해도 충분해요.
안 해도 다음 수업에서 starter 받고 같이 해요!

🟢
1. [ ] (구체적 1줄)
2. [ ] (구체적 1줄)

🟡 하고 싶으면
3. [ ] (선택 1줄)

❓ 막히면: 그냥 안 해도 됩니다.
```

### 과제 vs 수업 역할

| | 수업 (전원) | 과제 (선택) |
|--|-------------|-------------|
| 새 개념 | ✅ | ❌ |
| starter 첫 실행 | ✅ | △ 미리 해보기 |
| 🟢 완성 | ✅ | △ 복습 |
| 🟡🔴 | △ 시간 남으면 | ✅ |
| 통합·발표 | ✅ | ❌ |

## 4. 수준별 대응

### 느린 학생
- **완성본 starter**부터 실행 → 돌아가는 것 먼저
- 주석 표시된 줄만 수정
- 짝/멘토 (빠른 학생 1 + 느린 학생 1, 매주 교체)
- 체크리스트 3개면 OK

### 중간 학생
- 템플릿 + 「왜 이 줄이 필요한지」 1분 설명
- CSS·문자열은 실수 OK
- `{ }`, `" "` 짝 — 미리 강조

### 빠른 학생
- 🔴 선택 메뉴 (꾸미기, 기능 추가, 통합)
- **조교 역할** (옆 친구 🟢 도와주기 — 자원봉사 느낌)
- 발표 미리 연습

> 「Level 3까지 한 학생」과 「Level 1만 한 학생」을 **같은 기준으로 점수 매기지 않기**

## 5. 팀 구성 (선택)

2~3명 팀 + 역할 분담:

| 역할 | 담당 |
|------|------|
| 디자이너 | CSS, 레이아웃 |
| 코더 | JS, API |
| 발표자 | 시연, 설명 |

팀 🟢 = 공동 1개, 개인 🟡 1개 추가

## 6. 매주 수업 시작 루틴 (고정)

```
1. (2분)  "과제 안 해도 OK, 오늘 starter로 시작"
2. (5분)  starter 다운 → 전원 실행
3. (5분)  이번 주 🟢 목표 + 데모
4. (30분) 🟢 전원 완료
5. (20분) 🟡 / 🔴 또는 멘토링
6. (5분)  30초 시연
7. (1분)  선택 과제 🟢 2개 안내
```

**🟢 완료 손** — 완료 학생은 다음 레벨, 교사는 미완료 학생에 집중

## 7. 자주 생기는 상황

| 상황 | 대응 |
|------|------|
| API/코드 에러 | 미리 돌아가는 zip + 「에러 나면 starter 다시 받기」 |
| 빠른 학생 지루 | 🔴 메뉴 + 조교 + 다음 주 미리보기 |
| 3주 연속 🟢만 | OK — **누적 starter** (4주차까지 포함 버전) 별도 배포 |
| 「친구는 🔴인데 나만 🟢」 | 「이번 주 목표는 🟢. 🔴은 보너스」 반복 |

---

## 8. 수업 규칙 (1주차에 안내)

> 과제는 **연습용**입니다. 안 해도 다음 수업 **100% 따라갈 수 있게** 매주 starter를 드립니다.  
> 수업에서 **꼭 배울 내용은 다 합니다.** 과제는 더 해보고 싶을 때만 하면 됩니다.
