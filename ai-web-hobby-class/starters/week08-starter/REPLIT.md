# Replit 템플릿 — 8주차 starter (말풍선 채팅 UI)

질문·AI 답이 **말풍선**으로 쌓입니다. 기록은 Python `messages` list!

## 템플릿 만들기 (교사)

1. `week08-starter` 업로드 / Import
2. Secrets → `OPENROUTER_API_KEY`
3. Run → 질문 2번 보내 말풍선 확인
4. Create Template

## 학생 안내

1. Fork → Run
2. 질문 보내기 → 말풍선 확인
3. `.bubble-user` / `.bubble-ai` 색 바꾸기 (🟢)
4. (선택) 「지우기」 버튼 주석 해제 → `/api/clear` (🔴)

## 파일 안내

| 파일 | 8주차 |
|------|-------|
| `app.py` | `messages` list, `/api/chat` history, `/api/clear` |
| `templates/index.html` | 채팅창 |
| `static/script.js` | `appendMessage()`, Enter 전송 |
| `static/style.css` | 🟢 말풍선 색 |
