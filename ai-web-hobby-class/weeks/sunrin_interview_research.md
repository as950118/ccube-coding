## 사례 5: 한국디지털미디어고등학교(디미고) 2026학년도 입학전형요항 — 공식 PDF 확보 (2026-10-10)

- **출처**: 2026학년도 한국디지털미디어고등학교 신입생 입학전형요항(전기학교), dimigo-h.goeas.kr 공식 게시 (2025-09-02), 학교장 명의
  https://dimigo-h.goeas.kr/upload/dimigo-h/ba/2026/04/77735954-0520-4b35-9039-8ce04a3572a9.pdf
- **왜 유사학교로 채택**: 선린과 같은 IT계열 특성화고(전기학교). 실제 학생 문항 후기는 디미고도 공개 웹에서 확보 불가했으나, 공식 평가요소가 면접 시나리오 템플릿으로 직접 사용 가능.
- **전형 구조**: 진로적성(취업희망자) 특별전형 = 1단계(교과 60 + 생기부종합평가 20 + 활동증빙자료 60 + 자기소개서 20, 2배수 선발) → 2단계 **심층면접 40점**. 일반전형 = 1단계(교과 120 + 생기부종합평가 20, 2배수) → 2단계 **소질·적성검사 40점(50분) + 일반면접 20점**. 총점 200점.
- **심층면접 평가요소 (40점)**: ① 활동증빙자료 확인 ② 진로목표 및 학업역량·발전가능성 ③ 인성(도덕성, 성실성, 나눔·배려, 대인관계 능력 등) 및 단체생활 적응력 종합 평가
- **일반면접 평가요소 (20점)**: ① 인성(도덕성, 성실성, 나눔·배려 등) ② 의사소통 능력 및 단체생활 적응력 종합 평가
- **소질·적성검사 (40점, 50분)**: IT분야 소질·적성 — 중학교 정보교과 학업 역량, 문제해결 능력, 수리 추론 능력, 창의 융합적 사고 능력 등
- **전형 일정 타이밍 (2026학년도 기준)**: 원서접수 2025.11.05(수)~11.07(금) → 특별전형 2단계 대상자 발표 11.08(토) → 심층면접 11.10(월) → 일반전형 소질적성검사·면접 11.21(금) → 최종 합격자 발표 11.24(월). 선린(서울 전기학교 특성화고)도 비슷한 11월 중순 전형일 것으로 추정되나 선린 공식 일정은 미확보.
- **2027학년도 예고 변경사항** (디미고, 선린과 무관하나 참고): 1학년 2학기 성적 반영 확대, 자치회 임원활동 3회 이상 만점, 한국코드페어 수상자→자기추천 부문 변경, 북한이탈주민 소질적성검사 추가.
- **시나리오 작성 시사점**: 심층면접 3축이 곧 시나리오 3막 구조 — (막1) 자기 활동 증빙 확인: "이 활동 뭐야? 네가 한 거 맞아?" → (막2) 진로목표·발전가능성: "왜 선린/이 학과야? 입학 후 뭐 할 거야?" → (막3) 인성·단체생활: "갈등 경험? 팀에서 네 역할?". 3대 단골 질문(왜 만들었어/뭐가 어려웠어/어떻게 해결했어)은 막1의 코어. 코딩 시험 대비는 소질적성검사 요소 4가지(정보교과 기초, 문제해결, 수리추론, 창의융합)로 문제 유형을 나누면 됨.

## 후속 조사 결과 (2026-10-11, 라이브 브라우저)

### 네이버 자체 검색 — 특별전형(미래인재전형) 면접 구조 확인

- **출처**: 네이버블로그 '예소스스피치 광진' (2025.11.03, '선린인터넷고 면접 준비, 선린인터넷고 자소서&면접 준비 방법!') — 입시학원 홍보형 글
  - 특별전형(미래인재전형) 전형 요소: 출결 30점 + 봉사활동 10점 + **심층면접 60점**(작업기초역량 30 + 전공적합성 30) = 100점. **면접 비중 60%**. 일반전형(6~7명 선발)은 면접 없음.
  - 면접 당일 흐름: 대기실 입실 → 출석 확인·핸드폰 수거·유의사항 전달 → [학과별 면접 자료] 작성 → 면접 대기 → 심층 면접 (**면접관 3명 : 지원자 1명, 1인당 10분 내외**)
  - 자소서·학업계획서는 **면접 당일 30분간 자필 작성** 후 바로 학과별 면접자료 작성. 면접은 자소서·학업계획서·생기부·학과별 면접자료 기반 개별 심층면접.
  - 학과별 면접자료는 면접 당일 학과별 대기장소에서 작성, 지원자의 '전공 관련 기초능력 및 적성' 판단용.
  - 참고 일정(해당 글 기준): 특별전형 원서접수 11.21(금) 09:00~11.24(월) 17:00 → 면접 11.25(화)~11.26(수) → 합격자 발표 11.27(목) 10:00
- **출처**: 네이버블로그 '이루려거든 미루지말자'/KG아이티뱅크 노량진학원 (2023.08.29, '선린인터넷고등학교 자기소개서 와 적성평가문제') — 입시학원 홍보형 글
  - 미래인재전형은 내신 미반영. 생기부·출석·자소서·적성평가·심층면접으로 평가. 포트폴리오 폐지.
  - 자소서는 전형에 따라 '면접 당일 자필 작성' vs '미리 서류로 제출'로 방식이 다름.
  - 적성평가는 전형별(미래인재 vs 특별교육이수자)로 문제 유형이 다름. **점수에는 포함되지 않지만 면접으로 이어지는 시험**. 실제 예시 문제 원문은 미공개(학원이 "보유하고 있다"며 상담 유도).
  - 학원 교재 '선린고 면접' 책자 사진에 번호 매겨진 질문 목록(최소 21개 문항)이 있으나 사진이 흐릿해 판독 불가.
  - 필자 조언: "중학교 수준의 면접이라 생각하신다면, 큰 오산입니다."
- **카페 미리보기** (IT특성화고 전특모 카페, 로그인 필요로 본문 열람 불가)
  - '선린인터넷고 지원 및 후기' (2025.11.28): "선린인터넷고 면접, 코딩 실기 시험 수준과 내용은?" 질문에 "(저는 소프트웨어과로 지원했습니다) 문제는 5개로 출제되었습..." 답변 일부 확인 → 코딩 실기(적성) 문제가 5문항 출제된 정황.

### ⑥ '선린인터넷고 미래인재전형 면접 어떻게 진행되는지 궁금합니다' (해커, 2024.11.24)
- URL: https://cafe.naver.com/nomacomnovels2/36734 — "면접이 60퍼센트라 어떤식으로 진행되는지" 질문이나 답변 없음

### 종합 — 확인된 실제 면접 질문 패턴
1. 생기부의 미인정·결석·질병 관련 질문 (체력·성실성 확인, 미인정 아니어도 물어봄 — 고배점 정황)
2. 자소서 기반 꼬리질문 ("코딩 실력이 어느 정도인지, 이 프로젝트를 만들 때 뭘로 개발했는지"가 계속 이어짐)
3. 지필(코딩 문제)에서 틀린 것 같은 문제에 대한 면접관 질문 — 가장 어려웠다는 증언
4. 생기부 세특·자소서 위주 꼬리물기

### 종합 — 코딩 지필 출제 사례 (2026학년도 입시, 2025.11 면접 기준)
- 소프트웨어과 5문제 출제. 진법·수열 관련 문제 (기초 알면 풀이 가능, 사고력·시간관리 요구)
- 난이도 체감 엇갈림: "영재원 난이도보다 어렵다" vs "수학·컴퓨터를 어느 정도 알면 풀 수 있다"
- **공식 요강상 소질적성검사는 폐지됐으나, 면접 당일 대기 시간에 코딩 문제를 종이로 풀게 하고(회수) 그 결과가 면접 질문으로 이어지는 구조** — 공식 명칭으로는 심층면접의 '전공적합성(학과 기초능력·적성) 평가'에 해당하는 것으로 보임

### 종합 — 합격 팁
- 자소서는 "학교가 나를 뽑아야 하는 이유" 중심, 만든 프로그램·활동은 직접 설명 가능한 수준으로 작성
- 생기부 이상(미인정·결석) 있으면 반드시 소명 준비
- 모르는 질문은 "제가 아직 그 부분에 대해선 공부가 부족해서요"라고 솔직히 답하거나 양해 구하기
- 학원 없이도 합격 사례 다수 (영재원·방학특강·대회·동아리 활동 기반)
