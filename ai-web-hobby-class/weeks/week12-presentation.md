# 12주차 — 발표회 & 수료

**Phase:** 마무리 | **소요:** 60~90분 (또는 120분 발표 확장)

---

## 🟢 목표 (전원)

**1~2분** 내에 내 웹사이트를 **시연**하고, **한 가지 수정한 부분**을 말로 설명한다.

---

## 수업 흐름 (90분)

| 시간 | 내용 |
|------|------|
| 0~15분 | 발표 순서·Rubric 간단 안내 |
| 15~70min | 학생별 1~2분 시연 (15~20명 기준 조정) |
| 70~85min | 「우리 반 AI 웹 전시」 — #자랑 링크 모음 |
| 85~90min | 수료 멘트, 여름방학 계속하기 안내 |

---

## 발표 체크리스트 (학생용)

```
□ 브라우저에서 페이지가 열린다
□ AI 챗봇 또는 퀴즈 1개 이상 시연
□ (있으면) 이미지 분류 또는 웹캠
□ 내가 바꾼 부분 1가지 설명
```
