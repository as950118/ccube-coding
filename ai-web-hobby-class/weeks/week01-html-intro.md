# 1주차 — HTML: 나를 소개하는 페이지

**Phase:** 웹 기초 | **소요:** 60~90분

---

## 🟢 목표 (전원)

이름과 한 줄 소개가 있는 **웹 페이지**가 브라우저에서 열린다.

---

## 수업 흐름

| 시간 | 내용 |
|------|------|
| 0~10분 | starter 받기, 브라우저에서 열기, 「페이지란?」 |
| 10~25분 | HTML 태그: `html`, `head`, `body`, `h1`, `p`, `img` |
| 25~55min | 🟢: 이름·소개·좋아하는 것 1줄 수정 |
| 55~70분 | 🟡: `ul`/`li`로 취미 목록 |
| 70~85분 | 30초 시연 |
| 85~90분 | 선택 과제 안내 |

---

## starter 포함 기능

- 기본 HTML 뼈대
- placeholder 이름 「홍길동」, 소개 문장

---

## 🟢🟡🔴 과제

### 🟢 (10분, 선택)
1. [ ] `h1`에 내 이름 넣기
2. [ ] `p`에 자기소개 1문장 쓰기

### 🟡
3. [ ] 취미 3개 `ul`/`li` 목록

### 🔴
4. [ ] 프로필 이미지 `img` (URL 또는 placeholder)
