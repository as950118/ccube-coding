# 평가·발표회 가이드

## 1. 평가 철학 (취미반)

- **등급 경쟁 X** — 완료 + 성장 + 시연
- 🟢만 해도 **이번 주 pass**
- 🔴까지 한 학생과 🟢만 한 학생을 **같은 rubric으로 점수화하지 않음**

---

## 2. 주간 확인 (형성 평가)

| 항목 | 기준 |
|------|------|
| 참여 | 수업 중 🟢 시도 |
| 완료 | 수업 종료 시 🟢 달성 (과제 무관) |
| 성장 | 「오늘 바꾼 것」30초 설명 가능 |

**기록 방법 (간단):** 출석부 옆 🟢/△ — △는 다음 주 starter로 재도전 OK

---

## 3. 12주차 발표회

### 형식
- **1인 1~2분** 시연 + 「여기를 바꿨어요」 한 줄
- 팀이면 **발표자 1명** + 나머지는 Q&A 보조

### 발표 체크리스트 (학생용)

```
□ Replit URL / Deploy 링크가 열린다
□ AI 챗봇 또는 퀴즈 — 「Python이 AI를 불러요」 설명
□ (있으면) Teachable Machine
□ Python(app.py) 또는 HTML 중 수정한 곳 1가지
```

### Rubric (참고, 3단계)

| 항목 | ⭐ 기본 | ⭐⭐ 좋음 | ⭐⭐⭐ 훌륭 |
|------|---------|-----------|-------------|
| **실행** | 페이지가 열림 | 2개 이상 기능 동작 | 통합 페이지 안정적 |
| **설명** | 만든 것 1줄 | 바꾼 코드/디자인 설명 | 동작 원리 간단히 설명 |
| **창의** | starter 기반 | 색·문구·레이아웃 개성 | 🔴 기능 또는 독자적 아이디어 |

> ⭐만 받아도 **수료** — 취미반은 참여·완주가 목표

---

## 4. 중간 점검 (6주차, 선택)

- 「지금까지 만든 것」30초씩 시연
- 7~11주 방향만 짧게 피드백 (「챗봇 UI 더 꾸며볼래?」)
- **성적 X** — 격려 + 다음 starter 안내

---

## 5. 수료·인증 (선택)

- **수료증:** 「AI + 웹 프로그래밍 취미반 12주 수료」
- 조건: **8주 이상 참여** + 12주차 시연 (🟢 수준 OK)
- 🔴·조교·#자랑 활약 → 「특별 멘션」 한 줄 (경쟁 아님)

---

## 6. 학부모 공유 (12주차 후)

짧은 카톡/이메일:

```
AI웹반 12주가 끝났습니다 🎉

자녀분들이 HTML/CSS/JS 기초와 AI API 연결까지
「나만의 AI 학습 도우미」웹사이트를 만들었습니다.

발표회 사진/링크: [URL]

앞으로도 Replit/GitHub Pages 링크로
집에서 계속 수정해 볼 수 있습니다.
```
