attack() 안을 블록으로 나누면

각 블록은 나중에 별도 함수 이름으로 뺄 수 있는 후보입니다. (차시: materials/01-functions-lesson.md)

종료 확인 둘 중 HP 0 이하면 메시지만 보내고 끝
game_over?
↓
플레이어 데미지 굴리기 random.randint(10, 25)
roll_damage
↓
적에게 피해 적용 + HP 바닥 맞추기 0 미만이면 0
apply_damage
↓
적이 살아 있으면 반격 데미지 굴리기 → 플레이어에게 적용
counter_attack
↓
JSON 응답 만들기 막대·로그에 필요한 숫자/문자열
jsonify
확장 아이디어: 프론트는 이미 ?skill=을 붙여 보냅니다. 서버에서 skill을 읽어 “굴리기” 블록의 숫자 범위만 바꿔도 수업 목표가 한 번에 보입니다.
