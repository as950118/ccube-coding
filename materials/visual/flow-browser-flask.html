버튼을 누르면 무슨 일이 일어날까?

프로젝트: templates/index.html ↔ app.py

① 브라우저 JavaScript

  • 버튼 → attack(skill) 실행
  • fetch('/attack?skill=...')로 요청
  • 돌아온 JSON으로 로그·HP 막대 갱신
HTTP 요청 → HTTP 응답 (JSON) ←

② 서버 Python / Flask

  • @app.route("/attack")
  • 함수 attack()가 요청 처리
  • player, enemy HP 변경
  • jsonify({...})로 응답

수업 포인트: 같은 단어 attack이 브라우저와 서버에 둘 다 있어도 역할이 다릅니다. 브라우저 쪽은 “요청 보내기”, 서버 쪽은 “규칙 적용하기”입니다.
