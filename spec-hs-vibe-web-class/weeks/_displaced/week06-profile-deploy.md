## 1. 배포란 무엇인가

### 1.1. 로컬 vs 배포

| 로컬에서 열기 (지금까지) | 배포 (오늘) |
|---------------------------|--------------|
| `index.html`을 더블클릭해야 보임 | **URL만 있으면** 누구나 클릭해서 봄 |
| 내 컴퓨터가 꺼지면 못 보여줌 | 24시간 인터넷에 떠 있음 |
| “파일을 보내드릴게요” | “이 링크 눌러보세요” |

### 1.2. 좋은 프로필 웹 예시 비평 (활동 · 10~15분)

교사가 준비한 배포된 프로필/포트폴리오 웹 사이트 2~3개를 함께 본다.

관찰 포인트:
- 첫 화면(Hero)에서 **3초 안에** 무슨 사이트인지 알 수 있는가?
- 스크롤했을 때 **너무 길거나 짧지** 않은가?
- 링크(Projects, Contact)가 실제로 **작동**하는가?

**활동:** 좋았던 점 1개, 아쉬웠던 점 1개를 짝과 이야기하기.

### 1.3. 오늘 하지 않는 것 (Non-goals 안내)

- 커스텀 도메인 연결(예: `내이름.com`) — 필요하면 이후 자율 학습  
- 로그인·백엔드·데이터베이스 — 아직 정적 웹 단계  
- 여러 페이지 라우팅 구조 변경 — 5섹션 구조는 유지

> 배포 직후는 서버·클라이언트·도메인·호스팅 개념을 실습 경험에 빗대어 설명하기 좋은 타이밍이다 —
> [appendix/web-concepts-guide.md](../appendix/web-concepts-guide.md) 참고.

## 2. 배포 방법 선택

### 2.1. GitHub Pages vs Vercel

| | GitHub Pages | Vercel |
|---|---------------|--------|
| 준비물 | GitHub repo만 | GitHub 계정으로 로그인 |
| 설정 난이도 | 매우 쉬움 (Settings에서 켜기) | 쉬움 (Import 버튼) |
| URL 형태 | `아이디.github.io/저장소이름` | `프로젝트이름.vercel.app` |
| 자동 재배포 | push하면 자동 반영 | push하면 자동 반영 |
| 무료 사용 | O | O |

> **수업 표준:** 학급 정책에 따라 **하나로 통일** 권장 (섞어도 개념은 같음).  
> Private repo도 Pages/Vercel 배포는 가능하지만, **배포된 사이트 자체는 공개**된다는 점은 미리 안내.

### 2.2. 무엇을 고를지 헷갈릴 때

- 처음이라 **가장 단순하게** 시작하고 싶다 → GitHub Pages  
- 이후 React/Vite 등 **모던 스택**(7주차~)까지 이어가고 싶다 → Vercel

## 3. 첫 배포 함께 하기

### 3.1. GitHub Pages로 배포 (선택 A)

1. GitHub repo → **Settings → Pages**  
2. Source를 `main` 브랜치, 루트(`/`)로 설정 후 저장  
3. 1~2분 기다린 뒤 안내된 URL(`https://아이디.github.io/저장소이름`) 접속

### 3.2. Vercel로 배포 (선택 B)

1. [vercel.com]에서 **GitHub 계정으로 로그인**  
2. **Add New → Project**에서 내 저장소 Import  
3. 설정 변경 없이 **Deploy** 클릭  
4. 완료되면 `https://프로젝트이름.vercel.app` 형태 URL 제공

### 3.3. 검증 체크리스트

- [ ] 배포 URL을 **다른 브라우저(시크릿 창)** 에서 열어봤다  
- [ ] 가능하면 **휴대폰**으로도 열어봤다  
- [ ] 5섹션이 순서대로 보인다  
- [ ] 한글이 깨지지 않는다  

### 3.4. 자주 걸리는 지점 (교사 대응표)

| 증상 | 원인(대개) | 대응 |
|------|-----------|------|
| Pages에서 404 | 아직 빌드 중 · 브랜치/경로 설정 오류 | 1~2분 후 재시도, Settings 재확인 |
| 스타일이 안 먹음 | CSS 경로가 대소문자/상대경로 오류 | `styles/main.css` 경로 다시 확인 |
| 배포는 됐는데 예전 화면 그대로 | 브라우저 캐시 | 새로고침(Cmd/Ctrl+Shift+R) |
| Vercel Import 시 저장소 안 보임 | GitHub 권한 미승인 | Vercel의 GitHub App 권한 설정 확인 |

## 4. UI 개선 루프 (피드백 → Plan → 수정 → 커밋)

### 4.1. 왜 「루프」인가

배포는 끝이 아니라 **한 바퀴의 시작**이다.

```
피드백 받기 → (필요하면) Plan으로 계획 → AI와 수정 → 커밋 → push → 자동 재배포
```

### 4.2. 피드백 받는 법 (활동 · 5분)

짝 또는 옆 친구에게 배포 URL을 보여주고 딱 한 가지만 묻는다:

```
이 페이지에서 가장 먼저 눈에 걸리는 곳 1군데만 말해줘.
```

`notes/feedback.md`에 받은 피드백을 그대로 적는다.

### 4.3. 수정 프롬프트 (증상만 구체적으로)

```
피드백: (받은 내용 그대로)

구조(5섹션)는 유지하고, 이 피드백과 관련된 부분만 수정해줘.
과한 변경 금지 — 오늘은 다듬기 단계야.
```

### 4.4. 수정 후 커밋 · 재배포 확인

```
git add .
git commit -m "피드백 반영: (한 줄 요약)"
git push
```

push 후 1~2분 뒤 배포 URL을 새로고침해 **반영됐는지** 확인한다.  
**포인트:** 「고치면 자동으로 인터넷에도 반영된다」는 감각.

## 5. 모바일 체크

### 5.1. 확인 방법

1. 브라우저 창을 **좁게** 줄이거나, 개발자 도구의 모바일 미리보기 사용  
2. 가능하면 **실제 휴대폰**으로 배포 URL 접속  

### 5.2. 자주 깨지는 곳

- 제목(Hero)이 화면 밖으로 넘침  
- 버튼/링크 간격이 너무 좁아 누르기 어려움  
- 표(있다면)가 가로로 잘림

### 5.3. 수정 프롬프트

```
휴대폰 화면(약 375~400px)에서 (증상)이 보여.
구조는 유지하고 그 문제만 고쳐줘.
```

### 5.4. 검증

- [ ] 좁은 화면에서 가로 스크롤이 생기지 않는다  
- [ ] 글자가 화면 밖으로 넘치지 않는다

- [ ] Projects 카드 클릭 시 **정상 작동하는 링크**로 연결된다 (또는 현재 페이지임을 명시)

- Pages/Vercel 첫 배포는 **1~2분 지연**이 흔하다. 학생이 실패로 오해하지 않도록 미리 안내.  
- Private repo + Pages 조합은 **사이트 자체는 공개**된다는 점을 배포 전에 짚어준다. 진짜 비공개가 필요하면 배포를 미루고 교사와 상담.  
- 피드백 활동은 **한 가지만** 묻게 제한 — 너무 많은 지적은 오늘 범위를 넘어감.  
- 🔴는 시간 여유가 있는 학생만. 🟢🟡 없이 🔴로 바로 가지 않도록 안내.

### 설명용 한 장 요약 (칠판)

```
로컬 → 배포 (GitHub Pages / Vercel)
피드백 → Plan(필요시) → 수정 → 커밋 → push → 자동 재배포
모바일 확인 → 깨진 곳 1곳 이상 고치기
Projects → "이 사이트"를 첫 작품 카드로
결과 → 배포 URL = 포트폴리오 #1
다음 → Phase2 Starter Kit (Week7)
```

### FAQ

**Q. GitHub Pages와 Vercel 둘 다 해도 되나요?**  
A. 가능하지만 오늘은 **하나만** 확실히 끝내는 것을 권장. 여유 있으면 다른 하나는 🔴 도전으로.

**Q. 배포했는데 예전 모습 그대로예요.**  
A. 대부분 브라우저 캐시 또는 재배포 지연. 강력 새로고침 후 1~2분 기다리기.

**Q. 도메인을 사고 싶어요.**  
A. 오늘 범위 밖. 필요하면 가정에서 보호자와 상의 후 진행 — 수업 필수 아님.

**Q. Projects에 넣을 만한 다른 작품이 없어요.**  
A. 오늘 배포한 **이 프로필 사이트 자체**가 첫 작품. 그거면 충분히 🟢.

**Q. 피드백을 받았는데 구조를 다 바꾸고 싶어졌어요.**  
A. 오늘은 **다듬기**만. 큰 구조 변경 아이디어는 회고에 적어두고 다음 기회에.

## 부록 B — 배포 트러블슈팅 표

| 증상 | 우선 확인 |
|------|-----------|
| 페이지가 안 뜸 | 배포 완료까지 1~2분 대기했는가 |
| 스타일 깨짐 | CSS 파일 경로 · 대소문자 |
| 옛날 버전이 보임 | 브라우저 캐시 새로고침 |
| 링크 클릭이 안 됨 | href 경로 오타 · 절대/상대경로 |
| 한글 깨짐 | `<meta charset="UTF-8">` 존재 여부 |
