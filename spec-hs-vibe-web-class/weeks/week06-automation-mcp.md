# 6주차 — 자동화 입문 · 커맨드 · 서브에이전트 · MCP

**Phase:** 워크플로 | **소요:** 4시간  
**원본 대응:** S10, S14~S17 · M8, M11~M14 **압축**

---

## 🟢 목표 (전원)

Starter Kit에 **커스텀 커맨드 1개**를 추가하고,  
MCP가 무엇인지 설명한 뒤 **유용한 서버 1개**를 연결해 본다.

---

## 학습 포인트

- 커스텀 커맨드 = 반복 작업 버튼화 (예: `/commit`, `/review`)
- 서브에이전트 = 「역할 나누기」입문 (코드리뷰 한 번)
- MCP = 도구를 AI에 꽂는 플러그인
- 훅(Hooks) · Skills는 **개념만** (시간 남으면 데모)
