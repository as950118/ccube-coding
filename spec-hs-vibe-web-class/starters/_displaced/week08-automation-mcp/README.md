## 이 폴더 사용법

이번 주도 **새 저장소를 만들지 않는다.** 7주차 Starter Kit에 이어서 작업한다.

1. 자주 쓸 프롬프트 1개를 골라 커스텀 커맨드로 만든다 (`.claude/commands/`).
2. 커맨드를 실제로 한 번 실행하고, 결과를 스크린샷 또는 로그로 남긴다.
3. CLAUDE.md에 커맨드 사용법을 한 줄 추가한다.
4. (🟡) MCP 서버 1개를 연결해 실제로 질문해본다.
5. (🔴) 코드리뷰 서브에이전트로 방금 만든 커맨드 파일을 검토받아본다.

## 커맨드 만들기 프롬프트

```
아래 프롬프트를 커스텀 커맨드로 만들어줘. 이름은 /(원하는 이름).

(자주 쓸 것 같은 프롬프트 내용, 예: 변경사항을 요약해 커밋 메시지를 제안하고 커밋까지 실행)
```
