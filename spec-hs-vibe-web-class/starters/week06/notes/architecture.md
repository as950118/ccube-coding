# 클라이언트-서버-DB 구조 (오늘 그린 그림)

```
[클라이언트]  --- 요청(Request) --->  [서버(백엔드)]  --- 조회/저장 --->  [DB]
 (브라우저)                              (Flask)                        (SQLite)
              <--- 응답(Response) ---                <--- 결과 ---
```

## 오늘 만든 BBS에서 각 부분은 무엇인가

- 클라이언트(프론트엔드): (예: `templates/list.html` 등 — 브라우저에 보이는 화면)
- 서버(백엔드): (예: `app.py`의 라우트들 — 요청을 받아 처리하는 로직)
- DB: (예: `bbs.db`의 `posts` 테이블 — 글이 실제로 저장되는 곳)

## 요청 하나를 골라 순서대로 따라가 보기

예: "글쓰기 폼을 제출했을 때"

1. 클라이언트가 ( ) 요청을 보낸다
2. 서버의 ( ) 라우트가 요청을 받는다
3. 서버가 DB에 ( ) 쿼리를 실행한다
4. 서버가 클라이언트에게 ( )로 응답한다(예: 목록 페이지로 이동)
