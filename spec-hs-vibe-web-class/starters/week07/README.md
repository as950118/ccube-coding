## 이 폴더 사용법

이번 주는 **6주차 `week06-bbs/` 폴더를 그대로 이어쓴다.** 새 저장소를 만들지 않는다.

**2~5장(회원·권한 핵심)은 AI 없이 직접 코드를 작성한다.** AI는 7장(도전 과제)에서만 쓴다.

1. `users` 테이블과 `posts.user_id`를 직접 추가한다
2. 회원가입·로그인·로그아웃 라우트와 `signup.html` / `login.html`을 직접 작성한다
3. 글 작성·수정·삭제에 로그인·본인 검사를 넣는다
4. `notes/session-auth.md`에 세션·권한 흐름을 그린다
5. `notes/why-auth.md`에 회고를 남긴다
6. 시간이 남으면 🟡(상단 네비) → 🔴(댓글 등, 여기서만 AI)로 진행한다

## 포함된 파일

```
week07/

    └── why-auth.md            ← 왜 회원 기능을 넣었는가 · 회고 (신규 작성 권장)
```

## 성공 기준 (🟢, AI 없이)

- [ ] 회원가입 → 로그인 → 글쓰기 → 로그아웃 흐름이 동작한다
- [ ] 비로그인 상태에서 글쓰기가 막힌다
- [ ] 다른 사람 글은 수정·삭제할 수 없다 (화면 + URL 직접 입력)
- [ ] 목록·상세에 작성자 이름이 보인다

## 🔴 도전 과제 (여기서만 AI 사용)

회원·권한 핵심이 끝난 뒤에만 진행한다.

```
목표: BBS v1에 (댓글 / 내 글만 보기 / base.html 공통화 등)을 추가한다.

제약:
- 회원가입·로그인·본인 글만 수정/삭제는 그대로 유지
- app.py, templates/ 안에서만 수정

먼저 계획만 제안해줘.
```
