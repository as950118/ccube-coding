# Nova — 프로필 초안

궁금한 걸 웹으로 풀어 보는 중학생의 포트폴리오용 프로필 웹 초안입니다.

## 무엇인가요

Hero · About · Interests · Projects · Contact 5섹션으로 구성된
한 페이지 스크롤형 프로필 웹입니다. HTML/CSS로 만들었습니다.

## 왜 만들었나요

특목고 탐구·포트폴리오 준비 과정에서, 「한 번에 예쁜 결과」보다
구조를 먼저 정하고 → 만들고 → 고치는 과정을 남기고 싶어서 시작했습니다.

## 어떻게 열어보나요

`index.html`을 브라우저로 열면 됩니다. (배포 URL은 준비 중 — Week6 예정)
