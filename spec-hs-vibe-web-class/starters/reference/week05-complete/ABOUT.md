## 파일

```
week05-complete/
├── ABOUT.md            ← 이 안내 (교사용)
├── README.md           ← 완성된 프로젝트 README (학생 결과물 예시)
├── CLAUDE.md            ← 완성된 CLAUDE.md 예시
└── notes/
    └── commit-log.md   ← 커밋 기록 예시 (의미 단위 3개)
```

> 실제 `.git` 이력·GitHub 저장소는 포함하지 않습니다. `README.md`·`CLAUDE.md`·`notes/commit-log.md`가
> **결과물의 텍스트 예시**입니다. 시연 시에는 이 내용을 실제 Nova 예시 저장소(교사가 별도 관리)에 반영해
> 브라우저로 보여주는 것을 권장합니다.
