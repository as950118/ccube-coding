# 왜 공공데이터를 붙였는가 (예시)

지난주까지 게시판 안 데이터는 우리가 직접 쓴 글뿐이었다. 미세먼지처럼 매일 바뀌는 실제
데이터를 가져와 보여주면, 게시판이 "정보를 나누는 공간"에서 "정보를 확인하는 공간"으로도
쓰일 수 있다는 걸 확인하고 싶었다.

# 회고 3줄

잘된 점: API 실패 시 샘플 데이터로 대체하는 구조를 직접 만들어서, 발표 중 와이파이가 끊겨도 화면이 안 죽었다.
막힌 점: 처음엔 원본 JSON 구조를 안 보고 바로 파싱 코드를 짜려다 계속 `KeyError`가 났다.
다음에 하고 싶은 것: 지역별 조회 이력을 DB에 저장해서 시간에 따른 변화를 보여주고 싶다.
