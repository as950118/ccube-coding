# 오늘 연동한 공공데이터 (예시)

- API 이름: 한국환경공단_에어코리아_대기오염정보 (data.go.kr)
- 신청·승인까지 걸린 시간: 신청 후 약 10분 (자동승인)
- 받아온 원본 JSON 구조 (핵심 키만):
  `response.body.items[]` — 각 항목에 `stationName`, `pm10Value`, `pm25Value`, `khaiGrade` 등
- 내가 가공해서 뽑은 값: `station`, `pm10`, `pm25`, `grade` (등급 코드를 "좋음/보통/나쁨/매우나쁨" 문자열로 변환)

# 오늘 막혔던 점

- `pm10Value`가 가끔 빈 문자열로 와서 `int()`가 에러남 → `int(value or 0)`으로 방어
- 처음에 `.env`를 안 만들고 코드에 키를 바로 적었다가, 리뷰 중 지적받고 `.env`로 옮김
