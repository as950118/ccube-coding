# 김반장 학교생활 도우미 (school_bot)

Flask 웹 서버에 OpenAI API와 나이스(NEIS) 급식 공공데이터를 연결한 AI 학교생활 도우미입니다.

## 무엇인가요

- **급식 조회**: 학교 이름을 넣으면 나이스 공식 API로 오늘 급식 원문을 보여주고, AI가 요약·알레르기·칼로리를 **별도 영역**에 해설합니다.
- **공지 요약(단일 대화)**: 공지를 붙여넣으면 [일정 / 할 일 / 준비물]로 정리합니다. 이전 요청은 기억하지 않습니다.
- **김반장 챗봇(연속 대화)**: 이전 대화를 기억하며 답합니다. 「초기화」로 문맥을 지울 수 있고, 브라우저마다 대화가 따로 관리됩니다.
- **사진 분석**: 시간표·안내문 사진(JPG/PNG)에서 일정과 준비물을 읽어옵니다.

## 왜 만들었나요

AI가 그럴듯한 거짓말(환각)을 하지 않게 만들려면 어떻게 해야 하는지 직접 확인하고 싶었습니다.
시스템 지침으로 역할·규칙을 고정하고, 급식처럼 사실이 중요한 정보는 공공데이터 원문을 먼저 가져와
AI에게 근거로 준 뒤(Grounding), 원문과 AI 해설을 화면에서 분리했습니다.

## 어떻게 열어보나요

```
pip install -r requirements.txt
cp .env.example .env      # .env 를 열어 OPENAI_API_KEY 를 채운다 (PyCharm 실행 설정의 Environment variables에 넣어도 됨)
python app.py
```

`http://localhost:5001` 접속. **API 키는 `.env` / 환경 변수에만 두고, 코드·GitHub·화면에 절대 올리지 않습니다.**

## 한계

- 서버를 다시 켜면 챗봇 대화 기록이 사라집니다(메모리에 저장).
- 같은 이름의 학교가 여러 곳이면 첫 번째 결과를 씁니다.
- AI 해설과 사진 판독은 틀릴 수 있어 원문·원본 사진과 대조가 필요합니다.
