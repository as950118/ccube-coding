# AI를 서비스에 붙이면서 배운 것

AI에게 물어보는 것과 서비스에 AI를 붙이는 것은 다르다. 서비스에서는 키를 숨기고, 규칙(시스템 지침)을 고정하고,
사실이 중요한 정보(급식)는 공공데이터 원문을 근거로 주고, 원문과 AI 해설을 화면에서 구분해야 한다.
