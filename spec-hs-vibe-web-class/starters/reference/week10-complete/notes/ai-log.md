# 단일 대화 vs 연속 대화 실험

- 단일 대화: 「내일 체육 준비물은 물이야」 → 이어서 「내일 뭘 챙겨야 해?」를 각각 따로 호출했더니, 두 번째는 준비물을 모른다고 답했다.
- 연속 대화: 같은 두 문장을 대화 기록과 함께 보냈더니 「물」이라고 답했다. 「초기화」 후에는 다시 모른다고 답했다.
- 이유: 모델은 기억이 없다. 연속 대화는 **이전 대화를 매번 같이 보내서** 기억하는 것처럼 보이는 것이다.
