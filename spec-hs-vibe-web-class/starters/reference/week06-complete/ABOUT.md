# 웹은 어떻게 동작하는가 · 나만의 BBS (교사 참고 · 완성 예시)

**수업안:** [../../../weeks/week06-bbs-basics.md](../../../weeks/week06-bbs-basics.md)

학생용 starter는 [../../week06/](../../week06/) 입니다.
이 폴더는 **조교·교사 참고용**입니다. 수업 중(핵심 기능을 직접 작성하는 동안)에는 학생에게 통째로 배포하지 않습니다. 단, **수업 종료 직전** 시간 내에 못 끝낸 학생에게는 다음 주를 같은 출발선에서 시작할 수 있도록 **따라잡기용으로 전달해도 됩니다** — 자세한 기준은 [weeks/week06-bbs-basics.md](../../../weeks/week06-bbs-basics.md)의 "진행 팁"을 참고하세요.

## 이 예시에 대해

4~5주차 프로필 프로젝트와는 별개인 **새 프로젝트**입니다. Flask + SQLite로 동작하는 최소 게시판(BBS) 구현체이며, 수업안 5장(🟢 핵심 기능, AI 없이 직접 작성)·7장(🔴 AI 도전 과제)의 참고 코드를 그대로 담았습니다. `bbs.db`는 실행 시 자동 생성되므로 포함하지 않습니다.

**중요:** 5장(목록/상세/작성/수정/삭제)은 학생이 AI 없이 직접 타이핑하는 구간입니다 — 수업 중 이 `app.py`를 통째로 복사해 주지 않습니다. `/search`(검색)만 "AI 도전 과제로 만든 것"이라는 설정으로 넣어둔 예시입니다.

## 실행 방법 (시연용)

```
pip install flask
python app.py
```

`http://localhost:5001` 접속 → 목록·글쓰기·상세·수정·삭제·검색이 모두 동작하는지 확인.

## 확인 포인트

- app.py: 라우트마다 역할이 한 가지로 명확히 나뉘어 있는가? (목록/상세/작성/수정/삭제)
- SQL: 값 전달에 전부 `?` 파라미터를 쓰고 있는가? (직접 문자열 이어붙이기 없음, `/search`의 LIKE도 포함)
- notes/architecture.md: "클라이언트 = 어디, 서버 = 어디, DB = 어디"가 학생 눈높이로 구체적인가?
- 학생 결과물에서 목록/상세/작성/수정/삭제가 **AI 프롬프트 없이** 완성됐는지 (7장 도전 과제만 AI 사용 대상)
