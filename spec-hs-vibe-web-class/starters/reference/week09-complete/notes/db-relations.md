# 댓글 1:N 관계 워크시트

- `posts` 테이블의 기본키: `id`
- `comments` 테이블에서 `posts`를 가리키는 컬럼: `post_id`
- 글 하나에 댓글이 여러 개 달릴 수 있는 이유: `comments`의 여러 행이 같은 `post_id` 값을 가질 수 있기 때문 (1:N)
- 글 하나를 지우면 그 글의 댓글은? → 오늘 코드는 `delete_post`에서 `DELETE FROM comments WHERE post_id = ?`를 먼저 실행해 댓글도 함께 지운다. (안 지우면 "고아 댓글"이 DB에 남는다.)

# 오늘 막혔던 점

댓글 삭제 라우트에서 `comment["post_id"]`로 리다이렉트 대상을 정하는 걸 깜빡해서 처음엔 목록으로만 이동했다.
