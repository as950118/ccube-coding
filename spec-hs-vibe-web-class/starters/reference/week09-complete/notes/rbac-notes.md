# `make_admin.py` 실행 후 바로 권한이 안 바뀌었던 이유

세션(`session["role"]`)은 로그인할 때 한 번 저장된 값이라, DB의 `role`을 바꿔도 이미 로그인된 세션에는 반영이 안 된다. 로그아웃 후 다시 로그인해야 새 `role`이 세션에 들어간다.

# 오늘 막혔던 점

처음엔 `require_owner`를 삭제 라우트에도 그대로 써서 관리자가 남의 글을 못 지웠다. `require_owner_or_admin`으로 바꾸고 해결.
