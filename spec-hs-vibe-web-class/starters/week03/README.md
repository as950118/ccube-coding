# week03 — 자기소개 미니 웹페이지 (starter)

**수업안:** [../../weeks/week03-orientation-setup.md](../../weeks/week03-orientation-setup.md)

## 이 폴더 사용법

1. 이 폴더(`week03`)를 통째로 복사해 `week03-intro`처럼 이름을 바꾼 뒤, Cursor에서 **File → Open Folder**로 연다.
2. `index.html`을 열어 아래 프롬프트 템플릿으로 AI에게 자기소개 페이지 완성을 요청한다.
3. 완성되면 파일을 더블클릭하거나 브라우저로 드래그해서 열어 확인한다.

## 포함된 파일

```
week03/
└── index.html   ← 이름·소개 자리만 있는 최소 스켈레톤
```

`index.html`은 일부러 비워 두었다. 오늘 수업의 핵심은 **AI에게 직접 채우게 하고, 한 군데는 손으로 고쳐보는 것**이다.

## 프롬프트 템플릿

```
목표: 자기소개 미니 웹페이지를 만든다.

제약:
- index.html 파일 하나로 작성
- 한국어
- 제목(이름), 한 줄 소개, 관심사 3개
- 복잡한 프레임워크 사용 금지

완료 기준:
- 브라우저에서 열었을 때 내 이름이 보인다
```

## 성공 기준 (🟢)

- [ ] Cursor에서 이 폴더가 열려 있다
- [ ] `index.html`에 내 이름(또는 닉네임)이 보인다
- [ ] 브라우저에서 페이지가 정상적으로 열린다
- [ ] `<h1>` 텍스트를 직접 한 번 고치고 저장 → 새로고침해봤다

자세한 진행 순서, 🟡🔴 도전 과제는 [weeks/week03-orientation-setup.md](../../weeks/week03-orientation-setup.md) 참고.
