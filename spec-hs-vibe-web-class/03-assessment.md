# 평가 · 포트폴리오 · 발표회 가이드

## 1. 평가 철학

- **순위 경쟁 X** — 성장 · 과정 · 설명력
- 주간은 🟢 달성 = **pass**
- 최종은 「특목고에 바로 제출」이 아니라  
  **특목고 서류·면접에 쓸 수 있는 재료**를 갖추는 것

> 입시 컨설팅·합격 보장이 아님을 오리엔테이션에서 명시한다.

## 3. 포트폴리오 Rubric (12주 종료)

### 필수 패키지

| # | 항목 | 최소 기준 |
|---|------|-----------|
| 1 | 프로필 웹 | 배포 URL + 자기소개 + 프로젝트 링크 |
| 2 | 미니 웹앱 | 배포 URL + README (문제·해결·사용법) |
| 3 | 캡스톤 | 배포 URL + PRD + ROADMAP + 회고 |
| 4 | GitHub | 공개 repo 2개 이상, 커밋이 「한 덩어리」가 아님 |
| 5 | 발표 | 3~5분 시연 + Q&A 1문항 대응 |

### 수준 (참고용 3단계)

| 항목 | ⭐ | ⭐⭐ | ⭐⭐⭐ |
|------|----|------|-------|
| **실행** | 페이지 열림 | 핵심 기능 동작 | 안정적 + 모바일 고려 |
| **문제정의** | 주제가 있음 | 「누구의 어떤 고통」명확 | 특목고 관심사와 연결 설명 |
| **과정** | README 있음 | PRD/ROADMAP | 회고에 실패·수정이 보임 |
| **AI 활용** | AI로 만듦 | Plan·규칙 사용 | 워크플로우를 말로 설명 |
| **발표** | 시연 | 왜/어떻게 포함 | 질문에 근거 있게 답 |

> ⭐만으로도 **수료**. ⭐⭐⭐는 「입시 재료로 다듬을 준비됨」 신호.

## 5. 12주차 발표회 (면접형)

### 형식
- **1인 3~5분** (시연 2분 + 설명 2분 + 여유)
- 청중: 동료 + 교사 (+ 희망 시 학부모)

### 발표 스크립트 템플릿 (학생용)

```
1. 저는 ○○ 문제를 풀고 싶었습니다. (30초)
2. 그래서 이런 웹을 만들었습니다. (시연 90초)
3. AI와 이렇게 협업했습니다. (Plan / CLAUDE.md / 커밋 중 1가지)
4. 막혔던 점과 고친 점. (30초)
5. 다음에 하고 싶은 것. (20초)
```

### 예상 질문 (교사 뱅크)
- 이 프로젝트에서 **네가 직접 결정한 것**은?
- AI가 틀린 코드를 냈을 때 **어떻게 알아챘나?**
- 특목고에서 배우고 싶은 것과 **이 주제의 연결**은?
- 사용자(친구·가족)에게 써 보라고 했나? 반응은?
