## 개강 전 학부모 안내 (요지)

1. **목적:** AI와 협업해 웹을 만들고, 특목고에 쓸 수 있는 **포트폴리오·탐구 과정** 연습
2. **비목적:** 입시 컨설팅 · 합격 보장 · 알고리즘 전문 교육
3. **준비물:** 노트북, 충전기, GitHub 계정(학부모 동의), AI 도구 구독(별도 안내)
4. **시간:** 주 1회 4시간 × 12주, 결석 시 보충 자료 제공
5. **AI 윤리:** 「AI가 다 해줌」이 아니라 **협업·검증·설명**을 가르침

## 민감 이슈 FAQ (교사 답변 요지)

**Q. 꼭 Claude / Cursor여야 하나요?**  
A. 수업 표준은 Cursor입니다. 동일 계열 AI IDE로 대체 가능하나, 자료·데모는 Cursor 기준입니다.

**Q. 코딩을 몰라도 특목고에 도움이 되나요?**  
A. 「코딩 실력」보다 **문제 정의·실행·설명** 연습에 가깝습니다. 학교별 반영 방식은 다릅니다.

**Q. 과제 못 하면요?**  
A. 다음 수업은 새 starter로 참여합니다. 캡스톤 기간만 연속성이 중요해 보충을 권합니다.

**Q. 비용을 더 쓰게 되나요?**  
A. 필수 구독은 개강 전 고지한 범위입니다. 유료 API·도메인 등은 선택이며 강제하지 않습니다.
