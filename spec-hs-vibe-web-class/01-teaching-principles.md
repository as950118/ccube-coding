# 수업 운영 원칙 — 차별화 · 템플릿 · 4시간 운영

## 1. 핵심 원칙

### 「특목고형 = 결과 + 과정」
취미반은 「완주」가 목표이고, 이 반은 **설명 가능한 결과물**이 목표다.

매 주 학생에게 묻는다:

1. **무엇을** 만들었나? (URL / 화면)
2. **왜** 만들었나? (문제 한 줄)
3. **어떻게** 고쳤나? (시행착오 한 가지)

### 「같은 목표, 다른 깊이」

| 레벨 | 대상 | 하는 일 |
|------|------|---------|
| **🟢 Level 1** | 처음 · 환경 이슈 많은 날 | starter에서 **지정 구간만** 수정 → 배포까지 |
| **🟡 Level 2** | 대부분 | 기능을 이해하고 **한 단계 확장** |
| **🔴 Level 3** | 빠른 학생 | UI/기능 추가, 문서 고도화, 이전 주 통합 |

> 🔴은 「다른 숙제」가 아니라 **같은 프로젝트의 plus**.

### 「과제 ≠ 다음 주 입장권」
- 과제 미완이어도 다음 주 **100% 참여**
- 매주 **새 starter** (지난 주 핵심 포함)로 리셋 가능
- 단, **캡스톤(11~14주)** 은 연속성이 중요 → 결석 시 보충 가이드 제공

## 2. 바이브코딩 수업 규칙

### 학생이 지켜야 할 것
1. **목표를 먼저 말한다** — AI에게 바로 「만들어줘」부터 치지 않기
2. **Plan 모드로 큰 변경** — 구조·페이지 추가 전에는 계획 확인
3. **이해한 것만 커밋** — 모르는 코드가 쌓이면 교사에게 질문
4. **비밀 키는 커밋 금지** — `.env` / API 키 교육 (Week5~)

### 교사가 지키는 것
1. 라이브 데모는 **실패·수정 포함** (완벽한 시연보다 디버깅 과정)
2. 「내가 코딩해 줄게」보다 **프롬프트 코칭**
3. 환경 이슈는 **치트시트 + 조교/또래 헬퍼**로 병목 완화
4. 특목고 입시 **컨설팅은 하지 않음** — 「탐구 과정·포트폴리오 역량」만 다룸

## 3. starter 템플릿 설계

### 기본 구조 (웹)

```
weekNN-starter/
├── README.md           ← 오늘 🟢🟡🔴 + 제출 방법
├── index.html          ← 🟢 수정 구역 주석
├── styles/
│   └── main.css
├── scripts/
│   └── main.js
├── CLAUDE.md           ← 프로젝트 기억 (Week5~)
└── .gitignore
```

### 주석 패턴

```html
<!-- ===== [🟢] 여기만 바꾸세요 ===== -->
<h1>이름을 넣으세요</h1>

<!-- ===== [🟡] 섹션 하나 추가 ===== -->

<!-- ===== [🔴] 도전: 다크모드 / 애니메이션 ===== -->
```

### AI 도구용

```
# CLAUDE.md (발췌)
## 이 프로젝트
중학생 포트폴리오용 프로필 웹입니다.

## 규칙
- 한국어 UI
- 외부 API 키를 코드에 넣지 말 것
- 큰 변경 전 plan 제안
```

## 4. 4시간 운영 체크리스트

### 개강 전 (Week0)
- [ ] 기기 OS별 설치 가이드 PDF
- [ ] 학부모 구독·계정 안내 발송
- [ ] Discord/카톡 채널 · Drive 폴더
- [ ] 「오늘 막히면 이 순서」 포스터 (Wi-Fi → 로그인 → 폴더 열기 → 교사)

### 매주 수업 시작 5분
- [ ] 출석 · 배터리 · 충전기
- [ ] Cursor/Claude 로그인 상태
- [ ] 지난 주 URL이 열리는지 (안 되면 starter로 전환)

### 매주 수업 종료 5분
- [ ] 🟢 달성 여부 체크 (출석부)
- [ ] GitHub push / 배포 여부
- [ ] 다음 주 예고 1문장

## 7. 안전 · 윤리

- AI가 만든 코드를 **자기 결과로만 포장하지 않기** — 「AI와 협업」을 명시
- 타인 사진·개인정보·학교 실명 데이터 무단 사용 금지
- 크롤링·해킹·부정행위 관련 요청은 즉시 중단·교육
- 특목고 서류에 넣을 때는 **학교/지역 가이드라인**을 학생이 확인

| | 취미반 | 이 과정 |

| 문서 | 최소 | **PRD/ROADMAP/회고 필수** |

| 평가 톤 | 완주 격려 | 완주 + **설명력** |
