# 과정 개요

## 1. 과정 소개

중학생이 **AI 코딩 도구(Cursor · Claude Code)** 로 웹을 만들고,  
그 과정을 **특목고 탐구·포트폴리오**로 연결하는 **12주 · 주 1회 4시간** 과정입니다.

핵심은 「코드를 외우는 것」이 아니라:

> **문제를 정의하고 → AI와 계획하고 → 웹으로 구현하고 → 설명하는 힘**

이것을 업계에서 말하는 **바이브코딩(Vibe Coding)** 워크플로우로 훈련합니다.

---

## 2. 대상 · 선수 조건

### 대상
- 중학교 2~3학년
- 과학고 · 영재고 · 외고 · 국제고 등 **특목고 진학을 목표**로 하는 학생
- (선택) IT·SW 관련 특화 고교·영재학급 관심 학생

### 있으면 좋은 것
- 타이핑 · 파일/폴더 개념
- 영어 UI에 대한 거부감이 크지 않음 (도구가 영어 중심)

### 없어도 되는 것
- 사전 코딩 경험 (있으면 🟡🔴로 확장)
- 알고리즘 대회 실력
- 성인 인강 수준의 Claude Code 고급 기능 전부

---

## 3. 학습 목표

### 전체 목표 (12주 후)
- Cursor / Claude Code로 **웹 프로젝트를 처음부터 배포까지** 진행할 수 있다.
- **Plan 모드 · CLAUDE.md · Git** 을 일상 워크플로우로 쓴다.
- **PRD → ROADMAP → MVP → 회고** 문서를 스스로 쓸 수 있다.
- 자신의 프로젝트를 **3~5분 면접형**으로 설명할 수 있다.
- GitHub에 **포트폴리오 저장소 3개 + README** 를 남긴다.

### 특목고 연결 목표
| 입시에서 보는 것 | 이 과정에서 연습하는 것 |
|------------------|-------------------------|
| 탐구 주제의 명확성 | PRD · 문제 정의 |
| 과정과 시행착오 | ROADMAP · 회고 · Git 커밋 히스토리 |
| 결과물의 설득력 | 배포 URL · UI · 시연 |
| 발표·면접 | Week12 면접형 발표 |

### 기대하지 않는 것 (중학생 기준)
- Agent Teams · 대규모 하네스 엔지니어링 마스터
- Notion API / 복잡한 B2B SaaS 복제
- 상용 서비스 수준의 보안·결제·운영
- 알고리즘 심화 · CS 이론 전 범위

---

## 4. 3개월 로드맵 (Phase)

### Phase 1 — 바이브코딩 입문 (1~4주)
**목표:** 도구에 익숙해지고, **공개 가능한 프로필 웹**을 만든다.

- 터미널 · Git · Cursor · Claude Code 설치/기본
- 권한 · Plan 모드 · `/init` · CLAUDE.md 맛보기
- 프로필 웹 UI 개선 → GitHub Pages / Vercel 배포

### Phase 2 — AI 개발 워크플로우 (5~8주)
**목표:** 「시키는 대로」가 아니라 **워크플로우로** 웹앱을 만든다.

- 모던 웹 스택 감각 (HTML/CSS/JS + 필요 시 Vite/간단 프레임워크)
- 프롬프트 엔지니어링 · Starter Kit
- 커스텀 커맨드 · 서브에이전트 **입문**
- PRD/ROADMAP → 미니앱 MVP 배포

### Phase 3 — 특목고형 캡스톤 (9~12주)
**목표:** 관심 분야 문제를 웹으로 풀어 **입시 포트폴리오**로 묶는다.

- 주제 선정 (과학·사회·학습·지역 문제 등)
- 린캔버스 · PRD · ROADMAP
- 2주에 걸쳐 구현·배포
- 포트폴리오 패키징 + 면접형 발표

## 5. 권장 기술 스택

| 구분 | 추천 | 비고 |
|------|------|------|
| AI IDE | **Cursor** | 수업 표준 |
| AI CLI | **Claude Code** (또는 Cursor Agent) | 학부모 구독 안내 필요 |
| 버전관리 | **Git + GitHub** | 포트폴리오 필수 |
| 웹 기초 | HTML / CSS / JS | 1~4주 중심 |
| 웹 심화 | Vite + 간단 React **또는** 정적 멀티페이지 | 5주~ · 학년·수준에 따라 |
| 배포 | GitHub Pages / Vercel | 무료 티어 |
| (선택) BaaS | Supabase | 10~11주 🔴만 |
| (선택) MCP | Context7, Playwright 등 | 6주 이후 맛보기 |

> **원칙:** 도구를 늘리지 않는다.  
> 「Claude Code 인강의 30섹션」을 따라가지 않고, **웹 결과물 + 탐구 문서**에 필요한 것만 고른다.

상세: [appendix/tech-stack.md](appendix/tech-stack.md)

## 6. 수업 시간 배분 (4시간)

| 블록 | 시간 | 내용 |
|------|------|------|
| A | 0:00~0:25 | 지난 주 회고 · 오늘 개념 · 라이브 데모 |
| B | 0:25~1:25 | **함께 따라하기** (교사 주도, 전원 동기화) |
| — | 1:25~1:40 | 휴식 |
| C | 1:40~2:50 | **🟢 실습** (starter 기반, 순회 코칭) |
| — | 2:50~3:00 | 휴식 |
| D | 3:00~3:45 | **🟡/🔴 확장** · 프로젝트 자율 시간 |
| E | 3:45~4:00 | 30초~1분 공유 · 과제 · 다음 주 예고 |

### 4시간을 쓰는 이유
- 설치·계정·환경 이슈를 **수업 안에서** 해결
- 「듣고 끝」이 아니라 **당일 배포 URL**까지 가는 밀도
- 특목고형 **문서 작성 시간**을 확보 (PRD/회고)
