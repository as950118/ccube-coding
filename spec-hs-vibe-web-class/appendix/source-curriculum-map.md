## 설계 원칙 (왜 줄였나)

1. **연령:** 중학생에게 30섹션 밀도는 과함  
2. **목적:** 특목고 = 탐구 과정 + 설명 가능한 웹  
3. **시간:** 48시간으로 「설치~배포~발표」까지 닫아야 함  
4. **지속:** 수업 후에도 Cursor만으로 혼자 확장 가능한 **얇고 강한** 스택
