# 특목고 대비 · AI 바이브코딩 + 웹 — 14주 커리큘럼

**대상:** 중학교 2~3학년 · 특수목적고(과학고·영재고·외고·국제고 등) 진학을 준비하는 학생  
**기간:** 14주 (약 3개월)  
**주당:** 1회 · **4시간**  
**핵심 키워드:** Vibe Coding · Cursor · Claude Code · 웹 포트폴리오 · 탐구 과정 문서화

---

## 이 과정의 정체성

| ❌ 취미반 / 성인 인강 그대로 | ✅ 이 과정 |
|------------------------------|-----------|
| 짧은 체험 · 완성도 낮아도 OK | **포트폴리오급** 웹 결과물 2~3개 |
| Claude Code 기능 전부 마스터 | **실전에 쓰는 워크플로우만** 압축 |
| 코딩 문법 암기 | **AI와 협업해 문제를 웹으로 해결** |
| 결과물만 제출 | **PRD → ROADMAP → 구현 → 발표** (탐구 과정) |

> 참고한 성인 강의(「클로드 코드 완벽 마스터」)의 **핵심 워크플로우**를  
> 중학생·특목고 입시 맥락에 맞게 **14주 × 4시간**으로 재설계했습니다.

## 최종 포트폴리오 (특목고 제출용 패키지)

학생이 14주 후 가져가는 것:

1. **프로필 웹** — 나 · 관심 분야 · 프로젝트 링크
2. **미니 웹앱** — 실생활/학습 문제를 푼 작은 서비스
3. **캡스톤 웹앱** — 특목고 탐구 주제와 연결된 웹 프로젝트
4. **과정 문서** — PRD, ROADMAP, 회고 (「어떻게 생각했는가」)
5. **GitHub + 배포 URL** — 면접·서류에서 바로 보여줄 링크
