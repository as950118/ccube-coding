## 오늘 배우는 것

**BBS 확장 — 댓글 · 검색 · 권한(RBAC) · 실시간 채팅**

지금까지 게시판은 "나 혼자 쓰고 고치는" 공간이었습니다. 오늘은 다른 사람과 **상호작용**할 수
있는 커뮤니티로 업그레이드합니다 — 댓글로 반응하고, 검색으로 찾고, 관리자와 일반 회원의
역할을 나누고, 실시간으로 대화합니다.

## 오늘 만드는 것

8주차 BBS(회원·권한·공공데이터 대시보드)를 **커뮤니티 버전(v3)**으로 업그레이드합니다.
**댓글·검색·권한은 AI 없이 직접** 작성합니다. **실시간 채팅만 AI와 함께** 만듭니다 — 지금까지와
전혀 다른 새 개념(WebSocket)이 필요하기 때문입니다.

| 기능 | 난이도 | 내용 |
|------|--------|------|
| 댓글 | 🟢 | 글마다 댓글을 달고, 본인 댓글만 삭제 |
| 검색 | 🟢 | 제목·내용에 키워드가 있는 글만 찾기 |
| 권한(RBAC) | 🟡 | 관리자 계정은 남의 글 삭제·공지 고정 가능 |
| 실시간 채팅 | 🔴 (AI와 함께) | 새로고침 없이 메시지 주고받기 |

## 핵심 개념

- **1:N 관계**: 글 하나에 댓글 여러 개가 달리는 DB 구조
- **쿼리스트링**: `?q=검색어`처럼 URL에 검색 조건을 담아 서버에 전달하는 방법
- **RBAC(역할 기반 접근 제어)**: 사용자를 역할(일반/관리자)로 나눠 할 수 있는 일을 다르게 정하는 방식
- **WebSocket**: 요청/응답을 매번 주고받지 않고, 서버-브라우저가 계속 연결된 채로 실시간으로 메시지를 주고받는 방식

```
댓글: posts(1) — comments(N)
검색: /?q=키워드 → 제목·내용에서 LIKE 검색
권한: users.role('user'|'admin') → 관리자만 되는 일 구분
채팅: 매번 요청하지 않고 계속 연결 → 새 메시지가 즉시 도착
```

## 오늘의 순서

1. (🟢, AI 없이) 댓글 테이블·작성/삭제 라우트·화면
2. (🟢, AI 없이) 검색(`?q=`) — SQL LIKE
3. (🟡, 직접) 관리자 계정 만들기(`make_admin.py`) · 남의 글 삭제 · 공지 고정
4. (🔴, 여기서만 AI) `flask-socketio`로 실시간 채팅 — AI가 만든 코드를 읽고 설명할 수 있어야 함

## 준비물

- 8주차에 완성한 BBS 폴더 (회원가입·로그인·권한·대시보드까지 완성된 상태)
- `pip install flask-socketio` (4단계에서 사용)

## 오늘의 성공 기준

- [ ] 댓글을 쓰고, 다른 계정으로 봐도 댓글이 보인다
- [ ] `/?q=키워드`로 검색하면 해당 글만 목록에 남는다
- [ ] 관리자 계정은 남의 글을 삭제하고 공지를 고정/해제할 수 있다 (일반 계정은 못 함)
- [ ] (도전) 두 브라우저에서 채팅을 열면 새로고침 없이 메시지가 오간다
- [ ] 기존 게시판(목록·상세·작성·수정·삭제·회원·권한·대시보드)이 그대로 동작한다
