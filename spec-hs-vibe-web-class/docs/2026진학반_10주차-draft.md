## 1. 오늘 배우는 개념

### 1.1. AI 서비스의 요청/응답 사이클

지금까지 배운 웹 통신 사이클(브라우저 ↔ Flask ↔ DB)에 외부 LLM API가 추가된다.

1. 브라우저(사용자)가 공지 텍스트나 질문을 입력하고 전송한다.
2. Flask 서버(app.py)가 입력을 받아 OPENAI_API_KEY를 포함해 OpenAI API에 전달한다.
3. OpenAI 모델이 프롬프트 규칙에 따라 텍스트 응답을 생성한다.
4. Flask 서버가 결과를 템플릿에 담아 브라우저 화면에 렌더링한다.

> API 키는 **서버에만** 있습니다. 브라우저(HTML·JS)에는 절대 내려보내지 않습니다.

### 1.2. 오늘 배우는 4개 키워드

- **openai SDK**: OpenAI 모델 호출을 표준화된 인터페이스로 제공하는 공식 Python 라이브러리
- **단일 대화 vs 연속 대화**: 문맥 없이 단발로 호출하는 방식(Stateless) vs 대화 기록을 직접 쌓아 매번 함께 보내는 방식(Stateful처럼 보임)
- **System Instruction (instructions)**: 모델의 역할(페르소나), 응답 규칙, 환각 방지 제약조건을 고정하는 최상위 시스템 지침
- **Grounding (데이터 결합)**: AI의 자체 기억(추측)에 의존하지 않고, 실제 공공데이터(나이스 등)를 먼저 조회해 AI에게 근거로 제공하는 기법
- **함수 호출 (Tool calling)**: AI가 스스로 데이터를 조회할 수는 없으므로, "이 함수를 이런 값으로 실행해 줘"라고 **요청**만 하게 하고 실제 실행은 우리 코드가 하는 방식 (챗봇이 급식을 조회할 때 사용)

## 2. OpenAI API 기초 — 단일 대화와 연속 대화

### 2.1. 환경 준비

터미널에서 SDK를 설치한다.

```
python -m pip install -U openai
```

실행 환경 변수에 OPENAI_API_KEY를 등록한다. **코드 내에 API 키를 하드코딩하지 않는다.**
(PyCharm: Run → Edit Configurations → Environment variables에 `OPENAI_API_KEY=발급받은키` 입력)

> ⚠️ API 키는 비밀번호와 같습니다. 채팅방·GitHub·화면 공유에 절대 올리지 않습니다. 선생님이 준 키는 수업 후 폐기됩니다.

### 2.2. 단일 대화 (responses.create)

질문 한 번에 답변 한 번을 받는 구조다. 이전 질문과 답변은 다음 호출 시 자동으로 전달되지 않는다.

```python
# 2.2 단일 대화: 질문 한 번 = 답변 한 번. 이전 대화는 전달되지 않는다.
from openai import OpenAI

# 환경 변수 OPENAI_API_KEY를 자동으로 읽는다. 키를 코드에 적지 않는다.
client = OpenAI()
MODEL = "gpt-4.1-mini"

response = client.responses.create(
    model=MODEL,
    input="학교생활을 돕는 반장봇의 핵심 기능 3가지를 bullet point로 추천해 줘.",
)
print(response.output_text)
```

### 2.3. 연속 대화 (대화 기록 리스트)

OpenAI 모델은 이전 대화를 스스로 기억하지 못한다. 그래서 **질문과 답변을 `history` 리스트에 쌓고, 매번 통째로 함께 보낸다.** 이것이 "기억하는 것처럼 보이는" 원리다.

```python
from openai import OpenAI

client = OpenAI()
MODEL = "gpt-4.1-mini"

history = []  # 질문과 답변을 차곡차곡 쌓는 리스트

while True:
    question = input("나: ").strip()

    if question in ["exit", "종료"]:
        break
    if not question:
        continue
    if question == "초기화":
        history = []
        print("[시스템] 대화 문맥이 초기화되었습니다.")
        continue

    history.append({"role": "user", "content": question})
    response = client.responses.create(model=MODEL, input=history)  # 기록 전체를 보낸다
    answer = response.output_text
    history.append({"role": "assistant", "content": answer})
    print(f"AI: {answer}\n")
```

### 2.4. 검증 체크리스트

- [ ] 단일 대화를 두 번 연속 실행했을 때, 두 번째 실행에서 첫 번째 질문의 내용을 기억하지 못하는 것을 확인했다.
- [ ] 연속 대화에서 '내일 체육 준비물은 물이야'를 보낸 뒤 '내일 뭘 챙겨야 해?'라고 묻자 '물'이라고 답변한다.
- [ ] '초기화'를 입력한 뒤 다시 물어보면 이전 준비물 내용을 잊어버렸음을 확인했다.
- [ ] `history`를 print로 출력해서 무엇이 매번 함께 전송되는지 눈으로 확인했다.

## 3. 프롬프트 제어 — 시스템 지침(instructions)

### 3.1. 프롬프트 5대 구성 요소

AI가 그럴듯한 거짓말(환각, Hallucination)을 하지 못하도록 규칙을 정의한다.

- **역할**: 너는 학교생활 도우미 '김반장'이야.
- **할 일**: 제공된 공지에서 일정, 해야 할 일, 준비물을 정리해.
- **참고 자료**: 사용자가 입력한 공지 원문.
- **조건**: 원문에 없는 날짜와 준비물은 지어내지 말고 '확인 필요'라고 표시해.
- **출력 형식**: 일정 / 할 일 / 준비물 순서로 간결하게 작성해.

### 3.2. 시스템 지침 설정 코드

```python
# 3.2 시스템 지침(instructions): 역할·규칙·환각 방지 제약을 고정한다.
from openai import OpenAI

client = OpenAI()
MODEL = "gpt-4.1-mini"

system_prompt = (
    "너는 학교생활 도우미 '김반장'이야. "
    "오직 제공된 공지와 데이터에 근거해서만 답변해. "
    "공지에 명시되지 않은 날짜, 장소, 준비물은 절대로 추측하지 말고 '확인 필요'라고 표시해."
)

notice = "다음 체육 시간에는 운동화를 준비하세요. 비가 오면 교실에서 수업합니다."
prompt = f"아래 공지를 [일정 / 할 일 / 준비물] 순서로 정리해 줘.\n공지: {notice}"

response = client.responses.create(
    model=MODEL,
    instructions=system_prompt,
    input=prompt,
    temperature=0.2,  # 낮을수록 덜 창의적이고 더 일관된 답
)
print(response.output_text)

# 실험: instructions= 줄을 주석 처리하고 다시 실행해서, 날짜 정보가 없을 때 답이 어떻게 달라지는지 비교해 보자.
```

### 3.3. 검증 체크리스트

- [ ] 공지에 날짜 정보가 없을 때 임의의 날짜를 생성하지 않고 '확인 필요'로 출력한다.
- [ ] 지정한 출력 형식([일정 / 할 일 / 준비물])에 맞추어 답변이 생성된다.
- [ ] `instructions=` 줄을 주석 처리하고 다시 실행해 차이를 비교했다.

## 4. 멀티모달 — 이미지(공지·시간표) 분석

### 4.1. 이미지 전송 원리

이미지 파일을 base64 문자열로 바꾼 뒤 `data:` 주소로 만들어, 텍스트 프롬프트와 **같은 메시지의 content 리스트**에 함께 전달한다.

### 4.2. 이미지 분석 코드

```python
# 4.2 이미지(멀티모달) 분석: 텍스트 프롬프트와 이미지를 한 메시지에 함께 담는다.
import base64

from openai import OpenAI

client = OpenAI()
MODEL = "gpt-4.1-mini"

IMAGE_FILE = "notice.jpg"   # PNG라면 파일명과 아래 MIME 타입을 함께 바꾼다
MIME_TYPE = "image/jpeg"    # JPG → image/jpeg, PNG → image/png

with open(IMAGE_FILE, "rb") as file:
    image_b64 = base64.b64encode(file.read()).decode("ascii")

prompt = (
    "이 시간표/안내문 사진을 분석해 줘. "
    "1) 전체 일정이나 시간표 목록을 텍스트로 표기하고, "
    "2) 챙겨야 할 준비물을 요약해 줘. "
    "글자가 흐려 식별할 수 없는 부분은 '확인 필요'라고 표시해."
)

response = client.responses.create(
    model=MODEL,
    input=[{
        "role": "user",
        "content": [
            {"type": "input_text", "text": prompt},
            {"type": "input_image", "image_url": f"data:{MIME_TYPE};base64,{image_b64}"},
        ],
    }],
)
print(response.output_text)
```

### 4.3. 검증 체크리스트

- [ ] JPG 및 PNG 이미지 확장자에 맞는 올바른 MIME 타입(image/jpeg, image/png)을 지정했다.
- [ ] 이미지에 표기된 텍스트와 AI가 출력한 내용이 글자 단위로 일치하는지 대조했다.
- [ ] 글자가 흐린 사진에서 '확인 필요'가 표시되는지 확인했다.

## 5. 웹 서비스 연동 — Flask와 나이스 급식 API 결합

### 5.1. 나이스 API 연동 모듈 (neis.py)

급식 메뉴를 AI가 상상하게 두지 않고, 나이스 공공데이터 포털에서 직접 조회해 온다.
나이스 인증키는 선택입니다 — 없으면 샘플 모드(조회 5건 제한)로 동작하며 이 수업에는 충분합니다. 키가 있다면 코드가 아닌 환경 변수 `NEIS_API_KEY`에 넣습니다.

```python
import os
from datetime import datetime

import requests

BASE_URL = "https://open.neis.go.kr/hub"
TIMEOUT = 5  # 초. 응답이 없으면 무한정 기다리지 않는다.

# 나이스 급식 메뉴 뒤 괄호 숫자(알레르기 번호)의 공식 의미
ALLERGY_CODES = {
    1: "난류", 2: "우유", 3: "메밀", 4: "땅콩", 5: "대두", 6: "밀",
    7: "고등어", 8: "게", 9: "새우", 10: "돼지고기", 11: "복숭아", 12: "토마토",
    13: "아황산류", 14: "호두", 15: "닭고기", 16: "쇠고기", 17: "오징어",
    18: "조개류(굴, 전복, 홍합 등)", 19: "잣",
}


def _get(endpoint: str, **params):
    query = {"Type": "json", "pIndex": 1, "pSize": 5, **params}
    # 키는 코드에 적지 않고 환경 변수에서 읽는다. 없으면 샘플 모드(5건 제한)로 동작한다.
    api_key = os.environ.get("NEIS_API_KEY")
    if api_key:
        query["KEY"] = api_key
    try:
        return requests.get(f"{BASE_URL}/{endpoint}", params=query, timeout=TIMEOUT).json()
    except (requests.RequestException, ValueError):
        return {}


def get_school_code(school_name: str):
    """학교 이름 → (교육청코드, 학교코드, 학교이름). 못 찾으면 None. 같은 이름이 여럿이면 첫 결과."""
    res = _get("schoolInfo", SCHUL_NM=school_name)
    if "schoolInfo" not in res:
        return None
    row = res["schoolInfo"][1]["row"][0]
    return row["ATPT_OFCDC_SC_CODE"], row["SD_SCHUL_CODE"], row["SCHUL_NM"]


def get_meal(office_code: str, school_code: str, date: str | None = None):
    """급식 원문을 dict로 돌려준다(date는 YYYYMMDD, 생략하면 오늘). 급식이 없으면 None."""
    date = date or datetime.now().strftime("%Y%m%d")
    res = _get(
        "mealServiceDietInfo",
        ATPT_OFCDC_SC_CODE=office_code,
        SD_SCHUL_CODE=school_code,
        MLSV_YMD=date,
    )
    if "mealServiceDietInfo" not in res:
        return None

    rows = res["mealServiceDietInfo"][1]["row"]
    # 조식(1)·중식(2)·석식(3) 중 중식을 우선 사용한다.
    row = next((r for r in rows if r.get("MMEAL_SC_CODE") == "2"), rows[0])
    return {
        "date": date,
        "meal_name": row.get("MMEAL_SC_NM", ""),
        "menu": row["DDISH_NM"].replace("<br/>", "\n"),
        "calorie": row.get("CAL_INFO", ""),
        "nutrition": row.get("NTR_INFO", "").replace("<br/>", "\n"),
    }
```

### 5.2. Flask 메인 서버 (app.py)

> **챗봇은 어떻게 급식을 알까?** AI 모델은 인터넷이나 나이스에 직접 접속할 수 없습니다. 그래서 챗봇에게 `get_school_meal`이라는 **도구(함수) 설명서**(`MEAL_TOOL`)를 함께 보냅니다. 학생이 "9월 17일 급식 알려줘"라고 물으면 AI는 답 대신 "`get_school_meal(학교, 20260917)`을 실행해 줘"라고 **요청**하고, 우리 코드(`run_meal_tool` → `neis.py`)가 나이스에서 실제로 조회해 결과를 돌려줍니다. AI는 그 결과만 보고 답합니다. 급식을 AI의 기억에 맡기지 않는 Grounding을 챗봇에도 적용한 것입니다.

```python
import base64
import json
import os
import uuid
from datetime import datetime

import openai
from dotenv import load_dotenv
from flask import Flask, jsonify, render_template, request, session
from openai import OpenAI

import neis

load_dotenv()  # .env 파일이 있으면 환경 변수로 읽어 들인다 (PyCharm 실행 설정에 직접 넣어도 된다)

app = Flask(__name__)
app.secret_key = os.environ.get("SECRET_KEY", "dev-only-change-me")
app.config["MAX_CONTENT_LENGTH"] = 5 * 1024 * 1024  # 업로드 사진 5MB 제한

# 환경 변수 OPENAI_API_KEY를 자동으로 읽는다. 코드·화면·JS 어디에도 키를 쓰지 않는다.
client = OpenAI()
MODEL = os.environ.get("OPENAI_MODEL") or "gpt-4.1-mini"

SYSTEM_PROMPT = (
    "너는 학교생활 도우미 '김반장'이야. "
    "오직 제공된 공지와 데이터에 근거해서만 답변해. "
    "공지에 명시되지 않은 날짜, 장소, 준비물은 절대로 추측하지 말고 '확인 필요'라고 표시해."
)

# 챗봇용: 사용자가 대화 중에 알려준 내용은 근거로 쓰되, 대화에 없는 내용은 추측하지 않는다.
CHAT_PROMPT = (
    "너는 학교생활 도우미 '김반장'이야. 친절하고 간결하게 답해. "
    "사용자가 대화 중에 알려준 공지·일정·준비물은 기억해서 답에 사용해. "
    "학교 급식을 물으면 기억이나 추측으로 답하지 말고 반드시 get_school_meal 도구로 조회한 결과만 사용해. "
    "학교 이름을 모르면 먼저 물어보고, 한 번 알려준 학교 이름은 다시 묻지 마. "
    "대화나 도구 결과에 없는 날짜, 장소, 준비물은 절대로 추측하지 말고 '확인 필요'라고 표시해. "
    "마크다운 기호(#, *, **)는 쓰지 말고 일반 문장과 줄바꿈으로만 써."
)

# 챗봇이 필요할 때 스스로 호출하는 도구(함수 호출). 모델은 "조회해 달라"고 요청만 하고, 실제 조회는 우리 코드(neis.py)가 한다.
MEAL_TOOL = {
    "type": "function",
    "name": "get_school_meal",
    "description": "나이스(NEIS) 공식 데이터에서 학교의 특정 날짜 급식(중식) 메뉴를 조회한다.",
    "parameters": {
        "type": "object",
        "properties": {
            "school_name": {"type": "string", "description": "학교 이름 (예: 경기고등학교)"},
            "date": {"type": "string", "description": "조회할 날짜 YYYYMMDD. 오늘이면 생략"},
        },
        "required": ["school_name"],
    },
}

IMAGE_MIME = {".jpg": "image/jpeg", ".jpeg": "image/jpeg", ".png": "image/png"}

# 연속 대화: 사용자(브라우저 세션)마다 대화 기록 리스트를 따로 보관한다.
MAX_HISTORY = 20  # 최근 20개 메시지(질문+답변 10쌍)만 다시 보낸다
user_chats: dict[str, list[dict]] = {}


class AIError(Exception):
    """화면에 그대로 보여줄 수 있는 AI 호출 오류 메시지."""


def call_model(user_input, instructions=SYSTEM_PROMPT, tools=None):
    """OpenAI에 한 번 요청한다. 오류는 화면에 보여줄 AIError로 바꾼다.

    user_input이 문자열이면 단일 대화, 메시지 리스트면 대화 기록을 함께 보내는 연속 대화다.
    """
    try:
        return client.responses.create(
            model=MODEL,
            instructions=instructions,  # 시스템 지침(역할·규칙·환각 방지)
            input=user_input,
            temperature=0.2,
            **({"tools": tools} if tools else {}),
        )
    except openai.AuthenticationError:
        raise AIError("API 키가 올바르지 않아요. OPENAI_API_KEY 환경 변수를 확인하세요.")
    except openai.RateLimitError:
        raise AIError("요청이 너무 많거나 사용 한도를 넘었어요. 잠시 뒤에 다시 시도하세요.")
    except openai.OpenAIError as e:
        raise AIError(f"AI 호출 중 오류가 났어요. ({type(e).__name__})")


def ask(user_input, instructions=SYSTEM_PROMPT) -> str:
    return call_model(user_input, instructions).output_text


def get_user_key() -> str:
    if "user_key" not in session:
        session["user_key"] = str(uuid.uuid4())
    return session["user_key"]


def run_meal_tool(arguments: str) -> str:
    """모델이 요청한 get_school_meal 호출을 실제로 실행하고, 결과를 JSON 문자열로 돌려준다."""
    args = json.loads(arguments)
    date = args.get("date")
    if date:
        try:
            datetime.strptime(date, "%Y%m%d")
        except ValueError:
            return json.dumps({"error": "날짜 형식이 올바르지 않음(YYYYMMDD)"}, ensure_ascii=False)
    school = neis.get_school_code(args.get("school_name", ""))
    if school is None:
        return json.dumps({"error": "학교를 찾지 못함"}, ensure_ascii=False)
    meal = neis.get_meal(school[0], school[1], date)
    if meal is None:
        return json.dumps({"error": "해당 날짜의 급식 정보가 없음(주말·방학·휴업일일 수 있음)"}, ensure_ascii=False)
    return json.dumps({"school": school[2], **meal, "allergy_codes": neis.ALLERGY_CODES}, ensure_ascii=False)


def chat_reply(history: list[dict]) -> str:
    """대화 기록으로 답을 만든다. 모델이 급식 도구를 요청하면 조회해서 결과를 돌려주고 다시 묻는다."""
    today = datetime.now()
    instructions = CHAT_PROMPT + f" 오늘 날짜는 {today:%Y년 %m월 %d일} ({'월화수목금토일'[today.weekday()]}요일)이야."
    work = list(history)  # 도구 호출 과정은 이번 답변에만 쓰고, 저장하는 기록에는 남기지 않는다
    for _ in range(3):
        response = call_model(work, instructions, tools=[MEAL_TOOL])
        calls = [item for item in response.output if item.type == "function_call"]
        if not calls:
            return response.output_text
        work += response.output
        for call in calls:
            work.append({
                "type": "function_call_output",
                "call_id": call.call_id,
                "output": run_meal_tool(call.arguments),
            })
    raise AIError("조회가 너무 길어졌어요. 질문을 다시 해 주세요.")


def chat_with_history(user_key: str, message: str) -> str:
    history = user_chats.setdefault(user_key, [])
    history.append({"role": "user", "content": message})
    try:
        reply = chat_reply(history)
    except AIError:
        history.pop()  # 실패한 질문은 기록에서 뺀다
        raise
    history.append({"role": "assistant", "content": reply})
    del history[:-MAX_HISTORY]
    return reply


def brief_meal(school_name: str, meal: dict) -> str:
    """급식 원문(근거 데이터)을 먼저 주고, 그 안에서만 해설하게 한다 — Grounding."""
    allergy_table = ", ".join(f"{n}.{name}" for n, name in neis.ALLERGY_CODES.items())
    prompt = (
        f"아래는 나이스(NEIS) 공식 API에서 가져온 {school_name}의 오늘 {meal['meal_name']} 원문이야.\n"
        "이 원문에만 근거해서 답하고, 원문에 없는 메뉴·수치는 지어내지 말고 '확인 필요'라고 써.\n"
        f"[알레르기 번호표] {allergy_table}\n"
        f"[메뉴 원문]\n{meal['menu']}\n"
        f"[칼로리] {meal['calorie'] or '정보 없음'}\n"
        f"[영양정보]\n{meal['nutrition'] or '정보 없음'}\n\n"
        "1) 오늘 급식을 1~2문장으로 요약해줘.\n"
        "2) 메뉴 뒤 괄호 숫자는 알레르기 번호야. 번호표로 풀이해서 주의할 메뉴를 알려줘.\n"
        "3) 칼로리·영양정보가 있으면 짧게 해설해줘.\n"
        "마크다운 기호(#, *, **)는 쓰지 말고 일반 문장과 줄바꿈으로만 써."
    )
    return ask(prompt)


def summarize_notice(notice: str) -> str:
    """단일 대화: 이전 요청은 전혀 전달되지 않는다(Stateless)."""
    prompt = (
        "아래 공지를 [일정 / 할 일 / 준비물] 순서로 간결하게 정리해줘.\n"
        "공지에 없는 항목은 '확인 필요'라고 써. 마크다운 기호는 쓰지 마.\n"
        f"공지: {notice}"
    )
    return ask(prompt)


def analyze_image(file_storage) -> str:
    ext = os.path.splitext(file_storage.filename or "")[1].lower()
    mime = IMAGE_MIME.get(ext)
    if mime is None:
        raise AIError("JPG 또는 PNG 사진만 올릴 수 있어요.")

    image_b64 = base64.b64encode(file_storage.read()).decode("ascii")
    prompt = (
        "이 시간표/안내문 사진을 분석해 줘. "
        "1) 전체 일정이나 시간표 목록을 텍스트로 표기하고, "
        "2) 챙겨야 할 준비물을 요약해 줘. "
        "글자가 흐려 식별할 수 없는 부분은 '확인 필요'라고 표시하고, 사진에 없는 내용은 절대 지어내지 마. "
        "마크다운 기호는 쓰지 마."
    )
    # 텍스트 + 이미지를 한 메시지의 content 리스트에 함께 담는다
    message = [{
        "role": "user",
        "content": [
            {"type": "input_text", "text": prompt},
            {"type": "input_image", "image_url": f"data:{mime};base64,{image_b64}"},
        ],
    }]
    return ask(message)


@app.route("/", methods=["GET", "POST"])
def index():
    user_key = get_user_key()
    view = {
        "school_name": "", "meal_school": None, "meal": None, "ai_meal": None,
        "notice_text": "", "summary": None, "image_result": None, "errors": {},
    }

    if request.method == "POST":
        action = request.form.get("action")

        if action == "meal":
            view["school_name"] = request.form.get("school_name", "").strip()
            school = neis.get_school_code(view["school_name"]) if view["school_name"] else None
            if school is None:
                view["errors"]["meal"] = "학교를 찾지 못했어요. 정확한 학교 이름(예: 경기고등학교)을 입력하세요."
            else:
                office_code, school_code, school_full_name = school
                view["meal_school"] = school_full_name
                view["meal"] = neis.get_meal(office_code, school_code)
                if view["meal"] is None:
                    view["errors"]["meal"] = "오늘 급식 정보가 등록되지 않았습니다. (주말·방학·휴업일일 수 있어요)"
                else:
                    try:
                        view["ai_meal"] = brief_meal(school_full_name, view["meal"])
                    except AIError as e:
                        view["errors"]["ai_meal"] = str(e)  # 원문은 그대로 보여준다

        elif action == "notice":
            view["notice_text"] = request.form.get("notice_text", "").strip()
            if not view["notice_text"]:
                view["errors"]["notice"] = "공지 내용을 입력하세요."
            else:
                try:
                    view["summary"] = summarize_notice(view["notice_text"])
                except AIError as e:
                    view["errors"]["notice"] = str(e)

        elif action == "image":
            photo = request.files.get("photo")
            if photo is None or photo.filename == "":
                view["errors"]["image"] = "사진 파일을 선택하세요."
            else:
                try:
                    view["image_result"] = analyze_image(photo)
                except AIError as e:
                    view["errors"]["image"] = str(e)

    return render_template("index.html", history=user_chats.get(user_key, []), **view)


@app.route("/chat", methods=["POST"])
def chat():
    user_key = get_user_key()
    message = request.form.get("message", "").strip()

    if not message:
        return jsonify({"reply": "질문을 입력하세요."}), 400
    if message == "초기화":
        user_chats.pop(user_key, None)
        return jsonify({"reply": "[시스템] 대화 문맥이 초기화되었습니다."})

    try:
        return jsonify({"reply": chat_with_history(user_key, message)})
    except AIError as e:
        return jsonify({"reply": str(e)}), 502


@app.errorhandler(413)
def too_large(_):
    return "사진 용량이 너무 커요(5MB 이하). 뒤로 가서 작은 사진을 올려주세요.", 413


if __name__ == "__main__":
    app.run(debug=True, port=5001)
```

```html
            <input type="text" id="chatInput" placeholder="질문 (예: 경기고등학교 9월 17일 급식 알려줘)" onkeydown="if (event.key === 'Enter') sendChat()">
            <button type="button" onclick="sendChat()">전송</button>
            <button type="button" class="sub" onclick="resetChat()">초기화</button>
        </div>
    </section>

    <script>
        const box = document.getElementById("chatHistory");

        function addMessage(who, text) {
            const note = document.getElementById("emptyNote");
            if (note) note.remove();
            const row = document.createElement("div");
            const name = document.createElement("b");
            name.textContent = who + ": ";
            row.append(name, document.createTextNode(text));   // textContent 계열만 사용 → 응답 속 HTML이 실행되지 않음
            box.appendChild(row);
            box.scrollTop = box.scrollHeight;
        }

        async function postChat(message) {
            const formData = new FormData();
            formData.append("message", message);
            const res = await fetch("/chat", { method: "POST", body: formData });
            return (await res.json()).reply;
        }

        async function sendChat() {
            const input = document.getElementById("chatInput");
            const message = input.value.trim();
            if (!message) return;
            input.value = "";
            addMessage("나", message);
            addMessage("김반장", await postChat(message));
        }

        async function resetChat() {
            await postChat("초기화");
            box.innerHTML = "<div>[대화가 초기화되었습니다.]</div>";
        }

        box.scrollTop = box.scrollHeight;
    </script>
</body>
</html>
```

### 5.4. 검증 체크리스트

- [ ] 학교 이름을 입력하고 조회를 눌렀을 때, 나이스 API 원문 급식 메뉴가 정상 출력된다.
- [ ] AI 급식 브리핑 영역에 급식 원문에 기반한 요약 및 영양 설명이 함께 렌더링된다.
- [ ] 챗봇에 '9월 17일 급식 알려줘'라고 묻자 학교 이름을 되묻고, 알려주면 나이스 원문과 같은 메뉴로 답한다. (조회 결과를 챗봇 답과 하나씩 대조해 보자.)
- [ ] 급식이 없는 날(주말)을 물으면 지어내지 않고 '없다'고 답한다.
- [ ] 브라우저를 2개 띄웠을 때(시크릿 창 포함) 각 세션의 대화가 서로 섞이지 않고 독립적으로 동작한다.
- [ ] 포트 5001에서 실행 시 콘솔에 에러 로그 없이 정상 서빙된다.
- [ ] 주말처럼 급식이 없는 날에는 "등록되지 않았습니다"가 뜬다.

## 6. 트러블슈팅 및 최종 점검

| 증상 | 원인 및 해결 방법 |
|------|-------------------|
| ModuleNotFoundError: No module named 'openai' | 실행 인터프리터에 패키지가 설치되지 않음. python -m pip install -U openai 재실행 |
| OpenAIError: Missing credentials (api_key 관련) | 환경 변수 OPENAI_API_KEY 미설정. PyCharm 실행 설정의 Environment variables 확인 후 앱 재시작 |
| AuthenticationError (401) | API 키 오타·폐기. 선생님께 새 키를 받아 교체 |
| RateLimitError (429) | 분당 호출 제한 또는 사용 한도 초과. 무한 루프 내 반복 호출을 방지하고 요청 간격을 둠 |
| model_not_found (404) | 사용할 수 없는 모델 이름. 환경 변수 OPENAI_MODEL을 선생님이 알려준 이름으로 교체 |
| 사진 분석에서 400 오류 | GIF·HEIC 등 지원하지 않는 형식. JPG 또는 PNG로 저장해서 사용 |
| 다른 브라우저의 대화가 섞임 | 전역 변수 하나로 대화 기록을 공유함. session['user_key'] 기반 딕셔너리로 기록 분리 |
| 급식 정보가 없다고 나옴 | 주말·방학·휴업일이거나 학교 이름 오타. 급식이 있는 평일에 정확한 학교 이름으로 재시도 |

## 완성 확인 목록

- [ ] 단일 대화와 연속 대화의 코드 구조 차이(`input="..."` vs `input=history`)를 설명할 수 있다.
- [ ] 이미지와 프롬프트를 함께 AI에 전달하여 시각 자료를 분석할 수 있다.
