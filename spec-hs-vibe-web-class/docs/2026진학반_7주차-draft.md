## 오늘 배우는 것

**BBS 업그레이드 — 회원가입 · 로그인 · 권한**

지난주는 누구나 글을 쓸 수 있는 게시판(v0)이었습니다. 오늘은 **누가 썼는지**, **누가 고칠 수 있는지**를 코드로 정합니다. 4주차 Permission 개념이 실제 로그인·권한 검사로 이어집니다.

## 오늘 만드는 것

6주차 BBS를 **회원 기능 버전(v1)**으로 업그레이드합니다. **핵심 기능은 AI 없이 직접** 작성합니다. AI는 마지막 도전 과제(댓글 등)에서만 씁니다.

| 화면/기능 | 내용 |
|-----------|------|
| 회원가입 | 아이디·비밀번호로 계정 생성 |
| 로그인 / 로그아웃 | 로그인 상태 유지(세션) |
| 작성자 표시 | 목록·상세에 글쓴이 이름 |
| 권한 | 로그인해야 글쓰기, **본인 글만** 수정·삭제 |

## 핵심 개념

- **인증(Authentication)**: "너 누구야?" — 로그인
- **인가(Authorization)**: "너 이거 해도 돼?" — 본인 글만 수정/삭제
- **세션(Session)**: 서버가 로그인 상태를 기억하는 방법
- **비밀번호 해시**: DB에 비밀번호를 그대로 저장하지 않음

```
[회원가입] → users 테이블
[로그인]   → session에 user_id 저장
[글쓰기]   → posts.user_id = 내 id
[수정/삭제] → post.user_id == 내 id ?
```

## 오늘의 순서

1. (🟢, AI 없이) `users` 테이블 · 회원가입·로그인·로그아웃
2. (🟢, AI 없이) 글에 작성자 연결 · 로그인 필수 · 본인 글만 수정/삭제
3. (🟡, 직접) 상단 네비에 로그인 상태 표시
4. (🔴, 여기서만 AI) 댓글 · 내 글만 보기 · base.html 공통화 등

## 오늘의 성공 기준

- [ ] 회원가입 → 로그인 → 글쓰기 → 로그아웃 흐름이 동작한다
- [ ] 비로그인 상태에서는 글쓰기가 막힌다
- [ ] 다른 사람 글은 수정·삭제할 수 없다 (화면 + URL 직접 입력 모두)
- [ ] 목록·상세에 작성자 이름이 보인다
