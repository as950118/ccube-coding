## 오늘 배우는 것

**웹은 어떻게 동작하는가 — 클라이언트 · 서버 · DB**

지금까지 만든 사이트는 파일을 열면 끝인 정적 페이지였습니다. 오늘부터는 **데이터가 저장되고, 다시 불러와지는** 서비스를 만듭니다.

## 오늘 만드는 것

**나만의 BBS(게시판) v0** — Flask(백엔드) + SQLite(DB) + HTML(프론트)

**핵심 기능은 AI 없이 직접 코드를 작성합니다.** AI는 맨 마지막 도전 과제에서, 스스로 상상한 기능·스타일을 만들 때만 사용합니다.

| 화면/기능 | 내용 |
|------|------|
| 목록 | 저장된 글 제목이 리스트로 보임 |
| 상세 | 클릭하면 글 전체가 보임 |
| 작성 | 폼을 제출하면 DB에 저장됨 |
| 수정 | 기존 글 내용을 고쳐서 저장 |
| 삭제 | 글이 DB에서 제거되고 목록에서 사라짐 |

## 핵심 개념

- **클라이언트(프론트엔드)**: 사용자가 보는 화면
- **서버(백엔드)**: 요청을 받아 처리하는 로직 (오늘은 Flask)
- **DB**: 데이터가 실제로 저장되는 곳 (오늘은 SQLite)

```
[클라이언트] --요청--> [서버] --조회/저장--> [DB]
            <--응답--          <--결과--
```

## 오늘의 순서

1. Flask 설치 · 첫 라우트(`GET /`) 실행해 보기
2. SQLite `posts` 테이블 만들기
3. (🟢, AI 없이) 목록·상세·작성·수정·삭제 **직접 코드로** 구현
4. (🟡, 직접) 손으로 한 군데 고치기 · 최소 스타일
5. (🔴, 여기서만 AI 사용) 검색 · fetch 비동기 글쓰기 · 상상한 기능/스타일

## 준비물

- 노트북, Cursor/Claude Code
- 터미널에서 `pip install flask` 실행 가능 여부 확인

## 오늘의 성공 기준

- [ ] Flask 서버가 로컬에서 실행된다
- [ ] 글을 쓰면 목록에 나타나고, 수정·삭제도 동작하며, 서버를 껐다 켜도 남아 있다
- [ ] 목록 → 상세로 이동하는 링크가 동작한다
- [ ] 클라이언트-서버-DB 그림으로 오늘 만든 BBS를 설명할 수 있다
- [ ] 목록·상세·작성·수정·삭제를 AI 도움 없이 직접 작성했다
