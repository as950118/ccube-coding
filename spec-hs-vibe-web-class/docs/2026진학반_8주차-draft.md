## 오늘 배우는 것

**BBS 확장 — 공공데이터 API · 대시보드**

지금까지 게시판 안 데이터는 우리가 직접 쓴 글뿐이었습니다. 세상에는 정부·공공기관이 이미
모아 둔 데이터가 아주 많습니다 — 미세먼지, 날씨, 버스 도착 정보... 오늘은 그중 하나를
**가져와서(API 호출) → 정리해서(가공) → 보여주는(대시보드)** 기능을 게시판에 추가합니다.

## 오늘 만드는 것

7주차 BBS(회원·권한 있는 게시판)를 **공공데이터 대시보드 버전(v2)**으로 업그레이드합니다.
**핵심 기능은 AI 없이 직접** 작성합니다. AI는 마지막 도전 과제에서만 씁니다.

| 화면/기능 | 내용 |
|-----------|------|
| 인증키 발급 | 공공데이터포털에서 오픈API 신청 → `.env`에 저장 |
| API 호출 | `requests`로 미세먼지 데이터를 JSON으로 받기 |
| 데이터 가공 | 필요한 값(측정소·수치·등급)만 뽑아 정리 |
| 대시보드 | `/dashboard`에서 표 + 막대그래프로 보여주기 |
| 예외처리 | API 실패 시 샘플 데이터로 자동 대체 |

## 핵심 개념

- **오픈API**: 누구나 신청하면 쓸 수 있게 공개한 API
- **인증키(서비스키)**: API 서버에 "내가 누구인지" 증명하는 열쇠 — 코드에 직접 적지 않고 `.env`로 관리
- **요청/응답**: 우리가 보내는 질문(request) / API가 돌려주는 데이터(response, JSON)
- **파싱**: 받은 데이터에서 필요한 값만 꺼내 정리하는 것

```
공공데이터포털 → 인증키 발급 → .env
requests.get(...) → JSON 응답
파싱 → [{측정소, 수치, 등급}, ...]
실패하면 → 샘플 데이터로 대체
/dashboard → 표 + 막대그래프
```

## 오늘의 순서

1. (🟢, AI 없이) 공공데이터포털 인증키 발급 · `.env` 설정
2. (🟢, AI 없이) `requests`로 API 호출 · JSON 구조 확인
3. (🟢, AI 없이) 데이터 가공 함수 · `/dashboard` 라우트 · 표+막대그래프
4. (🟡, 직접) 지역 선택 드롭다운
5. (🔴, 여기서만 AI) Chart.js 그래프 · 조회 이력 저장 · 다른 공공데이터로 교체

## 준비물

- 7주차에 만든 BBS 폴더 (회원가입·로그인·권한까지 완성된 상태)
- [data.go.kr](https://www.data.go.kr) 회원가입 및 "한국환경공단_에어코리아_대기오염정보" **활용신청을 수업 전날 미리 완료**
  (승인 전이어도 샘플 데이터로 오늘 수업을 그대로 진행할 수 있습니다.)

## 오늘의 성공 기준

- [ ] `.env`에 인증키가 있고, 코드에는 키 문자열이 직접 보이지 않는다
- [ ] `/dashboard` 접속 시 지역별 표와 막대그래프가 보인다
- [ ] 인터넷을 끊거나 `.env`를 지워도 샘플 데이터로 화면이 뜬다 (서버가 죽지 않는다)
- [ ] 기존 게시판(목록·상세·작성·수정·삭제·회원·권한)이 그대로 동작한다
