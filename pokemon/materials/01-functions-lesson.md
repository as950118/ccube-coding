# 차시 1 — 함수로 게임 규칙 정리하기

**대상:** 중학생 · 파이썬 기초(변수, 조건, 딕셔너리) 경험 있음  
**소요:** 약 60~90분(실습량에 따라)  
**기준 코드:** 프로젝트 루트의 `app.py`, `templates/index.html`

---

## 1. 이 차시에서 배우는 것

- 긴 코드 한 덩어리를 **이름 있는 조각(함수)**으로 나누는 이유를 말로 설명할 수 있다.
- **매개변수**와 **반환값**을 사용해 “같은 규칙을 여러 번 쓰기”를 할 수 있다.
- (확장) 브라우저가 보내는 `skill` 값을 Flask에서 `request`로 받는 흐름을 이해한다.

---

## 2. 우리 게임이 동작하는 순간(개념)

브라우저에서 버튼을 누르면 JavaScript의 `attack(skill)`이 `/attack?skill=...` 주소로 요청을 보냅니다. 서버의 파이썬 함수 `attack()`이 그 요청을 받아 HP를 바꾸고, JSON으로 돌려줍니다.

**시각 자료:** `visual/flow-browser-flask.html` 을 같이 보면서 설명합니다.

---

## 3. 지금 `app.py`에서 함수가 하는 일

### 3-1. Flask “라우트 함수”

- `home()` — `/` 접속 시 HTML 페이지를 돌려줌  
- `attack()` — `/attack` 접속 시 전투 한 턴 처리 후 JSON  
- `reset()` — `/reset` 접속 시 HP 초기화 후 JSON  

이미 **함수**로 나뉘어 있습니다. 다만 `attack()` **안**이 한 번에 너무 많은 일을 합니다.

### 3-2. `attack()` 안에 숨은 “작은 일” 목록

아래는 현재 `app.py`의 흐름을 학생이 말로 나열하게 하기 좋은 체크리스트입니다.

1. 둘 중 하나라도 HP가 0 이하면 → “게임 종료”만 알리고 끝  
2. 플레이어가 주는 데미지 숫자 정하기 (`random.randint`)  
3. 적 HP에서 빼기  
4. HP가 0 아래로 내려가면 0으로 맞추기  
5. 로그 문자열 만들기  
6. 적이 살아 있으면 → 적 반격 데미지, 플레이어 HP 깎기, 또 0 이하 클램프  
7. JSON으로 `player_hp`, `enemy_hp`, `message` 보내기  

**시각 자료:** `visual/function-blocks.html` 에서 “블록 나누기” 그림과 연결합니다.

---

## 4. 왜 작은 함수로 쪼개나?

**같은 패턴이 두 번 나온다.**  
적 HP를 깎은 뒤 `if ... < 0: ... = 0` 하고, 플레이어 HP를 깎은 뒤에도 똑같이 합니다. 이 규칙을 `clamp_hp(누구)` 또는 `apply_damage(누구, 데미지)` 같은 함수로 모으면:

- 실수로 한쪽만 고치는 일이 줄어듦  
- 나중에 “최대 HP의 절반까지만 회복” 같은 규칙을 넣을 때 한곳만 고치면 됨  
- 테스트(또는 REPL에서 호출)하기 쉬움  

**한 줄 메시지(학생용):**  
> “라우트 함수는 **문 앞 안내 데스크**이고, 게임 규칙은 **뒤쪽 창고 함수들**에 두자.”

---

## 5. 실습 과제(난이도 순)

### A단계 — 이름 붙이기만 (난이도 ★)

다음 함수 껍데기를 파일 상단 근처에 만들고, `attack()` 안의 해당 줄을 함수 호출로 바꿉니다.

- `roll_damage(low, high)` → `random.randint(low, high)` 반환  
- `clamp_min_zero(hp)` → HP가 0 미만이면 0으로 바꾼 값 반환  

### B단계 — “딕셔너리 한 명”에게 데미지 주기 (난이도 ★★)

- `apply_damage(fighter, amount)`  
  - `fighter`는 `player` 또는 `enemy` 같은 딕셔너리  
  - `fighter["hp"]`를 `amount`만큼 줄이고, 0 미만이면 0으로  

`attack()` 본문은 짧아지고, “누가 맞았는지”만 인자로 넘기면 됩니다.

### C단계 — `skill` 반영 (난이도 ★★, 프로젝트와 직결)

`templates/index.html`은 이미 다음과 같이 보냅니다.

```javascript
fetch(`/attack?skill=${skill}`)
```

Flask 쪽에서 쿼리를 읽으려면 `request`가 필요합니다.

```python
from flask import request

skill = request.args.get("skill", "thunder")
```

`skill` 값에 따라 데미지 범위나 메시지 꼬리표만 바꿔도 수업 성취가 큽니다. (예: `heal`이면 데미지 대신 HP 회복)

### D단계 — 선생님 체크 포인트(품질)

게임 종료 분기에서 지금은 `player_hp` / `enemy_hp` 키가 없을 수 있습니다. 프론트는 항상 `data.player_hp`로 바를 그립니다.  
**과제:** 종료일 때도 HP 숫자를 JSON에 넣어 주기 — “API는 형식을 통일하자”는 교훈으로 좋습니다.

## 7. 교사용 대본(마크다운)

> 아래는 **말 그대로 읽거나 줄여 쓰기 좋은 흐름**입니다. 학급 분위기에 맞게 농담·예시만 조정하세요.

### 도입(약 5분)

“오늘은 새 문법을 외우는 날이 아니라, **이미 있는 코드를 더 예쁘게 나누는 날**이에요. `app.py`를 열어보면 `attack()` 함수가 있죠? 버튼 누를 때마다 이 함수가 돌아가요. 근데 안을 보면 한 함수가 너무 많은 일을 해요. 레시피로 치면 ‘요리 전체’가 한 문단에 다 붙어 있는 상태예요. 우리는 오늘 **자르기**를 연습합니다.”

### 개념(약 10분)

“함수는 **이름이 있는 상자**예요. 바깥에서 `상자이름(재료)`처럼 부르면, 안에서 계산하고 `return`으로 결과를 던져줄 수 있어요. 재료가 없으면 `()`만 비워도 되고요. 중요한 건 **한 함수가 한 가지 일**에 가까울수록 나중에 고치기 쉽다는 점이에요.”

### 코드 따라가기(약 15분)

“`attack()`을 천천히 내려가 봅시다. 여기서 HP를 깎죠? 그 다음에 ‘0보다 작으면 0으로’ 하는 코드가 또 나와요. 같은 패턴이 두 번 나오면 선생님은 항상 의심해요. ‘이거 함수 하나로 묶을 수 있나?’ 라고요.”

### 시각 자료(약 5분)

### 실습(약 25~40분)

“A단계부터 해보고 끝난 팀은 B단계. `skill`까지 손 본 사람은 옆 친구에게 데모해 주기.”

### 마무리(약 5분)

“Flask의 `attack`은 **웹에서 온 요청을 받는 함수**고, 우리가 만든 `apply_damage` 같은 건 **게임 규칙 함수**예요. 역할이 다릅니다. 다음 시간에는 이 `player`랑 `enemy` 딕셔너리 자체를 **같은 설계도(클래스)**로 바꿔 볼 거예요.”

## 8. 부록 — 참고 코드 스켈레톤(수업 후 배포용)

학생 파일을 망가뜨리지 않으려면 `app_practice_functions.py`처럼 복사본에서 진행해도 됩니다.

```python
import random
from flask import request


def roll_damage(low: int, high: int) -> int:
    return random.randint(low, high)


def clamp_hp(hp: int) -> int:
    return max(hp, 0)


def apply_damage(fighter: dict, amount: int) -> None:
    fighter["hp"] = clamp_hp(fighter["hp"] - amount)
```

> 주의: 위 `clamp_hp`는 “데이터 모델”에 따라 `min(max_hp)`까지 같이 쓸지 논의할 수 있는 **토론 거리**로 쓰면 좋습니다.
